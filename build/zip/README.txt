PalaTerm
========

Japanese / 日本語
-----------------
このフォルダ（PalaTerm）ごと、好きな場所に置いてください（例: C:\Tools\PalaTerm）。
インストールは不要です。PalaTerm.exe をダブルクリックで起動します。
初回起動時に Windows SmartScreen の警告が出た場合は「詳細情報」→「実行」を選んでください（exe は未署名です）。
データ（暗号化された機器一覧 data\、ログ logs\、書き出し export\）はすべてこのフォルダの中に作られます。
アンインストールはこのフォルダを削除するだけです。

使い方: https://kojio145.github.io/palaterm/manual.html
更新: 新しい PalaTerm.exe でこのフォルダの exe を置き換えるだけです（データはそのまま使えます）。

English
-------
Put this whole folder (PalaTerm) wherever you like (e.g. C:\Tools\PalaTerm).
No installation: double-click PalaTerm.exe.
If Windows SmartScreen warns on first run, choose "More info" then "Run anyway" (the exe is not code-signed).
All data (encrypted device vault in data\, logs in logs\, exports in export\) is created inside this folder.
To uninstall, delete the folder.

Manual: https://kojio145.github.io/palaterm/manual.html
Update: replace PalaTerm.exe in this folder with the new one (your data carries over).
