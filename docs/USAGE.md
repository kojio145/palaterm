# 使い方

## 初回起動

1. `PalaTerm.exe` をダブルクリック（インストール不要）。
2. 初回はマスターパスワードを設定します。機器の認証情報はこのパスワードで
   AES-256-GCM 暗号化され、`PalaTerm.exe` の隣の `data\palaterm_vault.enc` に
   保存されます。**平文では一切保存されません。**
3. 2 回目以降はマスターパスワードでロック解除します。

> 持ち運び: `PalaTerm.exe` と `data\` フォルダを一緒に USB 等へコピーすれば
> どの Windows でもそのまま使えます。
>
> 書き込み先: PalaTerm のデータ（vault・ログ・書き出し）はすべて exe の隣に作られます。
> 唯一の例外は WebView2 ランタイム自身のブラウザキャッシュで、Windows が
> `%APPDATA%\PalaTerm.exe\EBWebView\` に作ります（PalaTerm のデータは含まれません）。
> アンインストールは exe のフォルダの削除だけで済みます（必要ならこのキャッシュも削除してください）。

## 基本の流れ

### 1. コマンドセットを作る（「コマンドセット」タブ）

実行したいコマンドを 1 行 1 コマンドで登録します。例（設定バックアップ）:

```
show running-config
show version
show ip interface brief
```

### 2. 機器を登録する（「機器一覧」タブ）

「＋ 機器を追加」から以下を設定します。

- **名前**: ログファイル名に使われます（例: `core-sw1`）
- **ホスト / IP**、**接続方式**（SSH / Telnet / シリアル）
- **OSタイプ**: ログイン自動化のプロファイル（Cisco IOS / ASA, JUNOS, FortiGate,
  HPE, NEC IX/QX/WA, A10, Aruba, Yamaha RTX など 14 種）
- **コマンドセット**: 上で作ったセットを割り当て
- **認証情報**: ユーザー名 / パスワード / enable パスワード
  （SSH は公開鍵認証も選択可。Ed25519 / RSA / ECDSA 対応・パスフレーズ付き鍵可）
- **踏み台サーバ**（任意）: 「＋ 踏み台を追加」で**最大5段**まで登録可。外側（手前）から順に、
  各段の接続方式（SSH/Telnet）・ホスト・認証を設定します。

**一式書出・読込（CSVでの一括登録もここ）**: 機器一覧の「一式書出」で、対象グループ（または全機器）の
機器CSV（`devices.csv`）と、その機器が使う**コマンドセット・OSタイププロファイル**を
`exportundles\グループ名\` にまとめて書き出します（「全機器」はコマンドセット・プロファイルも全件含む完全なバックアップ）。
別の PalaTerm では「読込」でそのフォルダの `palaterm-bundle.json` を選ぶと一式が入ります。
`devices.csv` は Excel 等で編集でき、「読込」で CSV 単体を選べば機器だけを読み込めます（機器名をキーに、既存は更新・新規は追加）。
読み込む前に、新規・上書き・既存のまま残す件数が確認画面に出ます。同名のコマンドセット・プロファイルは
既定では既存を残し（他グループの設定を壊さないため）、チェックを入れた場合だけ上書きします。
CSV の踏み台チェーンは1列に `method:host:port:user:pass:auth:keyfile` を `|` で区切って複数段書け、
ジャンプコマンド・鍵パスフレーズ・レガシー暗号の有無は隣の `bastionExtras` 列（JSON）に入るので、CSV だけで機器を完全に復元できます。
※CSVには**パスワードが平文で書き出されます**。編集後は速やかに削除してください。

**一覧上で直接編集・複製・削除**: 機器一覧の表では、ホスト・接続方式・OS・コマンドセットを
セルで直接編集できます（編集内容は自動保存。認証情報や踏み台は「詳細」ボタンから）。各行の
「複製」で機器をコピー、「削除」で削除できます。ヘッダーのチェックボックスで**全選択/全解除**できます。

**入力チェック**: 保存時に、IPアドレス形式（例: `192.168.1111.1` のような不正値は拒否）・
必須項目・ポート範囲などを検証し、問題があればエラーを表示して保存しません。

**機器グループ**: 「機器グループ」ボタンから、よく使う機器の組み合わせを名前付きで保存できます。
機器一覧のグループ・チップや、実行タブのグループ選択から、そのグループの機器だけをワンクリックで
実行対象にできます。

### 3. 一括実行（「実行」タブ）

- 機器一覧でチェックを入れた機器が対象です。
- 「▶ 一括実行」で全対象へ並列接続。各機器の状態（接続中 / ログイン中 /
  実行中 / 完了 / エラー）がリアルタイムに表示されます。
- 完了後、各行の「ログ表示」でその場でログを確認できます。
- 「ログフォルダを開く」で保存先を開きます。

## 対話接続（1台に手動ログイン）

機器一覧または**実行タブ**の各行の **「接続」** ボタンで、その1台にログイン・enable昇格・
ページャ無効化まで自動で済ませた状態の端末が、**本ツールとは独立した別ウィンドウ**（タスクバーにも
別表示）で開きます。**複数機器へ同時に別ウィンドウで接続**でき、各ウィンドウは四辺・四隅から
自由にリサイズできます（表示列数も追従）。踏み台経由でも自動で通り抜けます。対話接続の内容も
**ログファイルに保存**されます（切断時に保存先を表示）。`exit` またはウィンドウを閉じて終了します。

貼り付けは **Ctrl+V**（Shift+Insert / Ctrl+Shift+V も可）。Windows のクリップボード履歴（Win+V）から
選んだ項目もそのまま貼り付きます。複数行を貼ると各行がそのまま機器へ送られるので、設定モードでの
貼り付けは内容を確認してから行ってください。コピーは Tera Term と同じく**マウスで範囲を選択するだけ**で
自動的にクリップボードへ入ります（ダブルクリックで単語選択）。Ctrl+C はコピーではなく機器への中断（^C）送信です。

## 機器グループ（会社単位）と対象選択フロー

機器は**グループ（会社・拠点など）単位**で管理します。「機器一覧」タブを開くと、まず
**グループ選択画面**が出ます。ここで次のいずれかを選びます。

- **＋ 新規グループ作成**: グループ名（例: A社）を入力して作成 → そのグループの空の一覧に移り、機器を追加していきます（追加した機器は自動でそのグループ所属）
- **既存グループ**: そのグループの機器一覧に移ります
- **全機器**: すべての機器を表示します

グループ選択画面ではカードを**ドラッグして並び順を変更**できます。グループ内一覧では上部の
「グループ名変更」「グループ削除」が使えます（削除しても機器は残り、グループ未設定になります）。
機器の所属は、機器編集の「グループ（会社）」欄でも変更できます。機器には**拠点（任意）**も設定でき、
パスワード欄は**目のマーク**で表示/非表示を切り替えられます。実行タブのグループ選択で、その
グループの機器だけを実行対象にできます。

**一式書出・読込はグループ単位**です。書き出しは対象グループ（または全機器）を選択、
読み込みはファイルのグループをそのまま使うか、まとめて特定グループへ割り当てるかを選べます。
CSVには group / site 列が含まれます（パスワードは平文なので取扱注意）。
コマンドセット・OSタイプ設定の各タブには単体ファイルの「読込」だけが残っています
（旧ツールの `.list` 形式の取り込みや、削除した標準プロファイルの復元用）。

## ログの保存先・命名

- 保存先: 「設定」タブの「ログ保存フォルダ」（既定 `logs`）配下に、
  実行ごとのフォルダ `log_YYYYMMDD_HHMMSS/` が作られます。
- ファイル名テンプレート（既定 `{host}_Config_{date}_{time}.txt`）で
  次のプレースホルダが使えます: `{host} {ip} {os} {date} {time} {hhmm}`

## 設定（「設定」タブ）

- **最大並列数**: 同時接続数（0 = 無制限）
- **接続タイムアウト / コマンドタイムアウト**（秒）

## 注意

- 本ツールは機器の設定変更（コマンド投入）も行えます。**本番機器での利用は
  必ず検証環境で確認し、所属組織のルールに従ってください。**
- 会社 PC で利用する場合は、自作ツールであっても社内の利用申請ルールを
  確認してください。
