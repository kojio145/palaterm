# 使い方

## 初回起動

1. Releases の `PalaTerm-vX.Y-win64.zip` を展開し、`PalaTerm` フォルダごと好きな場所に置いて、中の `PalaTerm.exe` をダブルクリック（インストール不要。データ・ログ・書き出しはこのフォルダの中に作られます）。
2. 初回はマスターパスワードを設定します。機器の認証情報はこのパスワードで
   AES-256-GCM 暗号化され、`PalaTerm.exe` の隣の `data\palaterm_vault.enc`（暗号化データ。以下 vault）に
   保存されます。**平文では一切保存されません。** 新しい vault には「サンプル」グループとサンプルのコマンドセットが入っています（英語 UI で作ると「Sample group」「[Sample] Cisco router」のような英語名）。
   exe を別のフォルダへ移した・置き直したときは、初回画面の案内どおり**新しい vault を作らず**、以前の `data\palaterm_vault.enc` を新しい exe の隣の `data\` へコピーしてください。
3. 2 回目以降はマスターパスワードでロック解除します（違うと「パスワードが違うか、ファイルが壊れています」と出ます）。
   vault が壊れて開けなくても、同じパスワードで 1 世代前の控え（`data\palaterm_vault.enc.bak`）が開けるときは「保管庫を復元」の確認が出て、「1 世代前から復元」で控えに戻せます
   （壊れたファイルは消さずに `data\palaterm_vault.enc.broken-日時` として残します。控えのあとの変更は戻りません）。
   新しい版の PalaTerm で保存した vault を古い版（v1.9.10 以降）で開くと「新しい版で保存された保管庫です」と出て、読み取り専用で開きます
   （「この版で編集する」を選べば保存できますが、新しい版で追加された設定は消えます）。
   ロック画面・初回画面の右上でも言語を切り替えられます。マスターパスワードの確認の不一致などの入力の誤りは、その欄の下に表示されます。
   最後に開いていたタブとグループは、再起動後もそのまま戻ります。ファイル・フォルダを選ぶ Windows のダイアログは UI の言語で出ます。
   本体のウィンドウは**タスクバーに隠れない大きさ**で開き、閉じたときの位置・大きさ・最大化のまま次回も開きます（`%LOCALAPPDATA%\PalaTerm\main-window.json`）。
   480×320 まで縮められるので、対話窓で作業する間は脇へよけておけます（狭いときはサイドバーと余白が細くなり、はみ出す分はスクロール）。

> 持ち運び: `PalaTerm.exe` と `data\` フォルダを一緒に USB 等へコピーすれば
> どの Windows でもそのまま使えます。vault には機器・認証情報のほか、SSH のホストキーと GUI の証明書の記録も入っているので、それらも一緒に移ります。
> 列幅や言語の選択はブラウザ側の保存（PC ごと）なので移りません。
> 言語の切替（サイドバー下）は画面を読み直しますが、ロックは解除されたままです（マスターパスワードの再入力は不要・v1.7.7）。
>
> 書き込み先: PalaTerm のデータ（vault・ログ・書き出し）はすべて exe の隣に作られます。
> `data\` には vault（`palaterm_vault.enc`）とその 1 世代前の `palaterm_vault.enc.bak`、予約の記録（`schedule-log.json`・`schedule-dirs.json`・`schedule-checked.json`。機器名・予約の ID・時刻などだけで認証情報は含みません）、
> 使用中の印 `palaterm.lock`（開いている PC 名・ユーザー・PID・開始日時。終了するとロックが外れます）、内部エラーが起きたときの記録 `error.log` が入ります。
> exe の外に書くのは次の 2 か所だけで、どちらにも機器・認証情報は入りません。
> - `%APPDATA%\PalaTerm.exe\`: 画面（WebView2）のプロファイル。WebView2 ランタイム自身のブラウザキャッシュ（`EBWebView\`）と、この PC で選んだ言語・列幅・文字サイズ・表示の色などの画面の設定です。
> - `%LOCALAPPDATA%\PalaTerm\`: 窓の位置と大きさ（`main-window.json`・`term-window.json`・`gui-window.json`。数値だけ）と、GUI の窓ごとの一時的な WebView2 プロファイル
>   （`GUI\w-<pid>-<ns>`。窓を閉じると消えます。強制終了で残った分は、次回の PalaTerm 起動時または GUI の窓を閉じたときに片付けられます）。
>
> アンインストールは exe のフォルダの削除だけで済みます（必要ならこの 2 つのフォルダも削除してください）。
>
> 二重起動: PalaTerm は 1 つのフォルダにつき 1 つだけ起動します（2 つ目を開くと、動いている方の窓が出ます）。同じフォルダを別のパス（ドライブ文字と `\\PC名\共有`、別の PC・別のユーザー）から開いたときは、
> 2 つ目は「この PalaTerm のフォルダは、別の場所で開かれている PalaTerm が使用中です」と、開いている PC 名・ユーザーを示して起動しません（同じ vault を 2 か所で開くと、あとから保存した側が上書きするため）。

## 基本の流れ

### 1. コマンドセットを作る（「コマンドセット」タブ）

実行したいコマンドを 1 行 1 コマンドで登録します。セット名は編集画面でいつでも変更でき、そのセットを割り当てている機器はそのまま新しい名前を使います（「複製」は元のセットの内容が入った**未保存の新しいセット**として、`_copy` 付きの名前で編集画面を開きます。その場で名前を付け直して「保存」するまで何も作られず、キャンセルすれば何も残りません）。既にある名前で新しいセットを作ろうとすると「「X」は既にあります」と止まり、上書きはしません。セットを削除するときは、そのセットを使っている機器の台数と機器名を確認に表示します。例（設定バックアップ）:

```
show running-config
show version
show ip interface brief
```

編集画面の **「＋ まとめて追加…」** を押すと小窓が開き、上のように 1 行 1 コマンドで入力して「追加」（または Ctrl+Enter）すると、
入力した行数ぶんのコマンドが待機 1 秒（リモート・シリアルとも）で末尾に一度に追加されます。

各コマンドは、送ったあと**機器のプロンプト（OS タイプの「プロンプト（コマンド完了の目印）」）が出るのを待ってから**、その行の待機秒だけ待って次へ進みます。

- **待つ文字列（任意）**: コマンドごとに、プロンプトの代わりに待つ文字を指定できます（例: `configure terminal` の行に `(config)#`）。
  機器の今の行がその文字で終わったら次のコマンドを送ります（文字そのまま・行末で一致。行の途中に出ただけでは待ち続けます）。出ないままコマンドタイムアウトになると、その旨がエラーに出ます。
  サンプルのコマンドセットには、各 OS タイプのプロンプトと同じ `#` が最初から入っています（v1.6.5 以前から使っている場合も、空欄のままのサンプルのコマンドにだけ一度入ります）。
- **待機秒を使う**（セット単位・既定オン）: オフにすると全コマンドの待機秒を使わず、プロンプト（または待つ文字列）が出たらすぐ次を送ります。
  待機秒の値は残るので、オンに戻せば元どおりです。一覧には「待機秒なし」と出ます。
- ファイル（`コマンド,リモート秒,シリアル秒`）では、待機秒を使わないセットは先頭に `# palaterm: pause=off`、
  待つ文字列はそのコマンドの直前の行に `# palaterm: wait=(config)#` と書きます（`#` 行なので旧版や旧ツールでは読み飛ばされます）。

### 2. 機器を登録する（「機器一覧」タブ）

「＋ 機器を追加」から以下を設定します（機器がまだ無いときは、一覧の中央に「＋ 機器を追加」「表で編集」「読み込み」の 3 つのボタンが出ます）。
編集画面は開くと機器名の欄にカーソルがあり、Ctrl+Enter で保存できます。グループが未設定の機器は「グループを選ぶ…」、所属済みなら「別のグループへ移す…」で所属を変えられ、
まだ無いグループ名を入れて保存すると「新しいグループとして作成しますか？」と確認します。

- **機器名**: 機器の名前。ログファイル名に使われます（例: `core-sw1`。同じグループの中で重複不可）
- **IPアドレス / ホスト名**（DNS 名も可）、**接続方式**（SSH / Telnet / シリアル）。シリアルの COM ポートは編集画面のドロップダウンで選びます（一覧は編集画面を開くたびに読み直し、隣の ↻ でも更新できます）。
  「自動検出」のままにできるのは **USB シリアル変換が 1 本だけ**（または COM ポートが 1 つだけ）のときで、
  変換ケーブルが 2 本以上のときは「COM ポートを指定してください」と止まります（機器ごとに別の COM ポートを指定すれば同時に使えます）。
  USB シリアル変換ケーブルは、先にメーカーのドライバを入れて COM ポートがデバイスマネージャーに出ている必要があります（PalaTerm は Windows が認識しているポートだけを一覧に出します）
- **OSタイプ**: ログイン自動化のプロファイル（Cisco IOS / ASA, JUNOS, FortiGate,
  HPE, NEC IX/QX/WA, A10, Aruba, ALAXALA AX, Yamaha RTX, Linux サーバ（一般ユーザー／root）など 17 種）
- **拠点（任意）／役割（任意）**: 本社・東京DC、コア・エッジ・FW などの自由なラベル。
  ログファイル名テンプレートの `{site}` / `{role}` に入ります
- **コマンドセット**: 上で作ったセットを割り当て
- **認証情報**: ユーザー名 / パスワード / enable パスワード
  （SSH は公開鍵認証も選択可。Ed25519 / RSA / ECDSA に加え、古い踏み台向けの DSA（`id_dsa`・PEM 形式 / OpenSSH 形式とも）も可・パスフレーズ付き鍵可。
  Tera Term マクロの `/auth=publickey /keyfile=… /passwd=…` に相当し、`/passwd` の値は「鍵のパスフレーズ」欄に入れます）
- **踏み台サーバ**（任意）: 「＋ 踏み台を追加」で**最大5段**まで登録可。外側（手前）から順に、
  各段の接続方式（SSH/Telnet）・ホスト・認証を設定します（SSH の踏み台はユーザー名が必須で、空のままでは保存できません。Telnet の踏み台は空でも可）。**踏み台の通り方**は 2 種類から選べます。
  - **踏み台上でコマンドを打つ**（標準）: 2段目以降と対象機器へは手前の踏み台上で `ssh` / `telnet` を打って進みます。
    ルーターなどシェルのある踏み台ならどれでも使えますが、公開鍵認証とレガシー暗号の許可は **1段目のみ**で、
    2段目以降の認証はその踏み台側の ssh クライアント（`~/.ssh` の鍵など）に依存します（ここで使われるのはユーザー名とパスワードだけ）。
  - **SSH トンネル**: 踏み台の SSH の中を通して、この PC から各段と対象機器へ直接ログインします（OpenSSH の `ProxyJump` と同じ）。
    **全段で**この PC の秘密鍵・パスフレーズ・レガシー暗号の設定・ホストキー確認が効き、踏み台では何も打ちません（ジャンプコマンド欄は使いません）。
    踏み台はすべて SSH で、TCP 転送（`AllowTcpForwarding`、Linux の OpenSSH は標準で許可）が必要です。対象機器は SSH / Telnet。
    転送を許可していない踏み台では「転送を許可していません」と表示されるので、「踏み台上でコマンドを打つ」にしてください。
    手動接続（Shift+クリック）では対象機器の画面が直接開きます。
  踏み台の OpenSSH が古い機器の方式を拒否して `Unable to negotiate … Their offer: ssh-dss` のように止まった場合は、
  提示された方式を `-o HostKeyAlgorithms=+ssh-dss` のように自動で足して打ち直します（鍵交換・暗号・MAC も同様）。
  踏み台上で打つ標準のコマンドには、次の段（または機器）のポートが 22（Telnet は 23）以外なら `ssh -p 2222 user@host` ／ `telnet host 2323` のようにポートが付きます（v1.7.3）。
  「踏み台上でコマンドを打つ」で踏み台からその先へ入れなかったとき（接続の拒否・タイムアウト・名前解決の失敗など、または踏み台のプロンプトに戻った）は、
  「踏み台から 192.0.2.20 へ接続できませんでした（踏み台の表示: "…"）」のように踏み台の表示と確かめることを出して、その機器を止めます。**コマンドセットを踏み台で実行することはありません**（対話接続の自動ログインも同じ）。
  ログイン後のプロンプトが踏み台のプロンプトと同じときも、踏み台に戻っている可能性があるため中止します。機器と踏み台のホスト名が本当に同じなら、どちらかのホスト名を変えてください。
- **自分の踏み台を先に通る**（v1.7.4）: 社内の踏み台のように**人ごとに秘密鍵が違う踏み台**は、「設定」タブの**自分の踏み台**（最大5段）に IP・ユーザー名・秘密鍵などを登録し、
  機器の編集画面で「**自分の踏み台（設定タブ）を先に通る**」にチェックします。機器には「使う」ことだけが保存され、IP や認証情報は書き出されません。
  受け取った人は自分の踏み台を登録すれば、そのまま全台に入れます。その先に機器ごとの踏み台（お客様の踏み台など）を最大5段足せます。踏み台の通り方（コマンド入力 / SSH トンネル）は機器の設定が全体に効きます。
  自分の踏み台が未登録のまま接続すると「設定タブの『自分の踏み台』に登録してください」というエラーになります（直接つなぎに行くことはありません）。
- **CLI を使う / GUI を使う**（v1.7.4）: 機器ごとに、CLI（SSH / Telnet / シリアルでのログイン）と GUI（ブラウザの管理画面）を使うかを選べます（既定は CLI オン・GUI オフ）。
  CLI をオフにした GUI だけの機器は、「接続」が押せず、一括実行・接続確認・予約の対象（実行タブ・予約の台数）にも出ません。GUI を使う機器には IP アドレスが必要です。編集画面では接続方式・OS タイプ・コマンドセット・踏み台の欄が隠れ、
  機器一覧では接続・OS・コマンドセットの欄が「GUI のみ」と GUI の方式・ポート（例: `https:443`）の表示になります（v1.7.5）。
  「自分の踏み台を先に通る」「CLI を使う」「GUI を使う」は、機器一覧で複数台を選んだ「一括変更…」でもまとめて変えられます（v1.7.5）。
- **GUI**（v1.7.3・v1.7.4 で変更）: 「GUI を使う」をオンにした機器は、機器一覧の **「GUI」** で FortiGate などの**管理画面を PalaTerm の窓で開き、機器のユーザー名・パスワードで自動ログイン**します
  （グループ既定の認証情報を使う機器はそちら）。オフの機器はボタンが押せません。**踏み台は通らず、機器のアドレスへ直接開きます。**
  編集画面で **GUIの方式**（https / http）と **GUIポート**（https は 443、http は 80 が既定。方式を切り替えると既定に合わせ、変えている番号はそのまま）を指定します。
  - 自己署名の証明書でもブラウザの警告画面（「詳細設定」→「進む」）を出さずに開きます。代わりに SSH のホストキーと同じく**初回の証明書を記録し、次から変わっていたら開かずに止めます**
    （機器の入れ替え・証明書の更新なら、窓のメニュー「証明書の変更を許可」で開けます）。
  - **初めて開く機器**（証明書を記録した直後）は、ユーザー名・パスワードを入れるだけで送信はしません。内容を確かめて「ログイン」を押してください。2 回目からは自動でログインまで進みます
    （初めての場所で、同じ IP の別の機械にパスワードを送ってしまわないため。ブラウザが信頼する正規の証明書の機器は初回から自動です）。
  - ログイン前・ログイン後の同意画面（Disclaimer の「Accept」など）は自動で押します。ログインの送信は**窓を開いて最初の 1 回だけ**で、ログインした後のページ（パスワード変更の画面など）には何も入れません。
    パスワード違いで何度も送ってロックアウトされることもありません。セッションが切れたときはメニュー「ログインし直す」で自動ログインします。
  - Cookie などは窓ごとに持ち、**窓を閉じると消えます**（次に開くときは同意画面・ログインからやり直し、自動で進みます）。リンク先の別のサイトは既定のブラウザで開きます。
  - 窓のメニュー「既定のブラウザで開く（自動ログインなし）」で Chrome などに切り替えられます。メニューには「← 戻る」「進む →」「URL をコピー」もあります（v1.7.7）。ロック・終了で GUI の窓は閉じます。http を選んだ機器は、パスワードが暗号化されずに送られる旨を編集画面に表示します。
  - GUI の窓は本体の窓の中央（同じモニタ）に、画面の拡大率に合わせた大きさで開き、変えた大きさは次回も使われます（`%LOCALAPPDATA%\PalaTerm\gui-window.json` に記憶）。ログイン欄が見つからないページでは、タイトルに「ログイン欄を見つけられませんでした。手で入力してください（ユーザー名: …）」と出るので、そのまま手で入力できます。
    GUI の窓を操作している間は本体の「アイドル時の自動ロック」の操作として数えるため、使っている GUI の窓がロックで閉じられることはありません（v1.7.7）。

**一式書き出し・読み込み（CSVでの一括登録もここ）**: 機器一覧の「一式書き出し」で、対象グループ（または全機器）の
機器CSV（`devices.csv`）と、その機器が使う**コマンドセット・OSタイププロファイル**を
`export\bundles\グループ名\` にまとめて書き出します（「全機器」はコマンドセット・プロファイルも全件含む完全なバックアップ。機器が 1 台も無いときはボタンが押せません）。
別の PalaTerm では「読み込み」でそのフォルダの `palaterm-bundle.json` を選ぶと一式が入ります。
`devices.csv` は Excel 等で編集でき、「読み込み」で CSV 単体を選べば機器だけを読み込めます（「グループ名＋機器名」で照合し、既存は更新・新規は追加）。現在の列構成の見本（ラボ用の架空値）がリポジトリの `examples/devices.sample.csv` にあります。読み込み前の確認画面には、内容に問題がある行（IP の形式違い、踏み台経由なのにユーザー名に `;` `$` などの記号、ネットワーク上の秘密鍵パスなど）と、同じグループ＋機器名が重複した 2 行目以降が「読み込まない行」として表示されます。踏み台の**ジャンプコマンド**が入った行は、その文字列が踏み台でそのまま実行されるため、確認画面に内容が表示されます。書き出した CSV では、`=` `+` `-` `@` で始まる値（Excel が数式として実行してしまう）の先頭に `'` が付きます。読み込むときに自動で外れるので、そのまま編集・読み込みできます。
読み込みは **先にファイルを選び**、次の 1 画面で「所属グループ」「同名のコマンドセット・プロファイルを上書きするか」（一式のときだけ）と、
新規・上書き・既存のまま残す件数を見ながら決めます（選択肢を変えると件数も更新されます・v1.7.7）。同名のコマンドセット・プロファイルは
既定では既存を残し（他グループの設定を壊さないため）、チェックを入れた場合だけ上書きします。
読み込みに失敗したときはダイアログが開いたままなので、ファイルや選択肢を直してやり直せます。グループへ読み込んだあとは、そのグループの一覧に移ります。
一式書き出しは同じフォルダ（`export\bundles\グループ名\`）に書くため、前回の書き出しが残っているときは上書きしてよいか確認します（Excel で編集中の devices.csv を消さないため）。
CSV は **1 つの列に 1 つの値**です。画面が日本語なら見出しも日本語（「機器名」「IPアドレス」「ユーザー名」…）で、
接続方式は SSH / Telnet / シリアル、認証方式は パスワード / 公開鍵、はい / いいえ のように書かれます（英語の見出し・値でも読めます）。
踏み台は段ごとに「踏み台1_ホスト」「踏み台1_ポート」「踏み台1_ユーザー名」「踏み台1_パスワード」「踏み台1_認証方式」「踏み台1_鍵ファイル」
「踏み台1_鍵パスフレーズ」「踏み台1_旧暗号を許可」「踏み台1_ジャンプコマンド」（2 段目は「踏み台2_…」）。通り方は機器の列「踏み台の通り方」（`コマンド入力` / `SSHトンネル`、英語は `shell` / `tunnel`。空欄はコマンド入力）。踏み台を使っていなくても
「踏み台1_…」の列は出るので、Excel で踏み台を書き足せます。v1.6.4 以前の CSV（`bastions` 列に `ssh:…` を詰めた形式）もそのまま読めます。
**逆に、この形式の CSV・一式は v1.6.4 以前の PalaTerm では踏み台が読み込まれません**（踏み台なしの機器として入ります）。受け取る側も v1.6.5 以降にしてください。
Excel で「CSV（コンマ区切り）」（Shift_JIS）として保存し直したファイルも読めますが、文字化けを避けるには「CSV UTF-8（コンマ区切り）」での保存がおすすめです。
※CSVには**パスワードが平文で書き出されます**。編集後は速やかに削除してください。

**踏み台の認証情報を含めない（人に渡す用・v1.7.3）**: 一式書き出しでこれにチェックを入れると、機器ごとに登録した踏み台の**ユーザー名・パスワード・秘密鍵ファイル・鍵のパスフレーズを空欄**にして書き出します
（踏み台のホスト・通り方・ジャンプコマンドと、機器自身のユーザー名・パスワードは残ります）。チェックの状態は次回も引き継がれます。
「自分の踏み台を先に通る」機器は、このチェックに関係なく自分の踏み台の IP・認証情報が書き出されません（CSV の列「自分の踏み台を使う」に はい / いいえ だけが入ります）。

**読み込みでは、既存の機器（グループ名＋機器名が一致）の行で認証情報の欄が空なら、その機器の今の認証情報を残します**
（認証情報の欄を空にした CSV を読み込んでも自分のパスワードは消えません。踏み台は同じ段・同じホストのときだけ引き継ぎ）。
欄に値があればその値で上書きします。確認画面に、引き継ぐ機器の台数が出ます。

**並び替え・絞り込み・列幅**: 機器一覧・グループ一覧・コマンドセット・OSタイプ設定・実行履歴・予約・変換ルール（一覧の取り込み）の各一覧は、実行タブと同じく
**見出しクリックで並び替え**（再クリックで逆順・「並び順を戻す」で登録順に。IP アドレスや末尾の番号は数の順＝`10.0.0.2` が `10.0.0.10` の前）、**絞り込み欄**で文字（機器一覧はグループ名、コマンドセットはコマンド本文も対象）や
拠点・グループで絞り込めます（「全機器」の一覧には「グループ」列と「グループ: すべて」の絞り込みがあります。拠点の絞り込みは、その拠点が無いグループへ移ると「すべて」に戻ります）。表示だけの操作で保存順は変わりません。機器一覧・コマンドセット・OSタイプ設定・変換ルールは左端の ⠿ を**ドラッグして並び順を変えられ**（グループ一覧はカードをドラッグ）、並び替え・絞り込み中はドラッグでの順序変更ができません。
見出しの境目を**ドラッグすると列幅**を変えられ（境目の**ダブルクリックで列の中身に合わせた幅**、もう一度ダブルクリックで既定の幅に戻る・この PC に記憶）、切れている文字はセルにカーソルを合わせると全文が出ます。
表の行を**右クリック**すると「選択した文字／このセル／この行／表示中の表をすべて」をコピーできます（行・表はタブ区切りなので Excel にそのまま貼れます。見出しのない列＝チェック・ボタン列は含みません）。

**一覧上で直接編集・複製・削除**: 機器一覧の表では、機器名・IP アドレス・拠点・役割・接続方式・OS・コマンドセットを
セルで直接編集できます（編集内容は自動保存。前のセルの保存が終わる前に次のセルへ打ち始めても入力は残り、日本語入力の変換も途切れません。認証情報や踏み台は各行の「編集」から）。各行の
「複製」は、元の機器の内容が入った**未保存の新しい機器**として編集画面（「機器を複製」）を開きます（名前と IP を打ち直して保存。キャンセルすれば何も残りません）。「削除」で削除できます。左端のチェックで選んだ機器は**一括変更・一括削除**できます（下の節）。

**表で編集（Excel のようにまとめて編集）**: 機器一覧の「表で編集」で、そのグループ（または全機器・グループ未設定）の機器を
**CSV と同じ列の表**として編集できます（認証情報・踏み台 1〜5 段・踏み台の通り方も。「列の表示…」で出す列を選べ、この PC に記憶）。
- 操作は Excel と同じです: クリック／Shift+クリック／ドラッグで範囲、行番号・見出しで行・列全体、Ctrl+A。矢印・Tab・Enter で移動、
  文字を打つか F2・ダブルクリックで編集、Esc で取消、Delete で空に、Ctrl+Enter で選択範囲すべてに同じ値。
  OS タイプ・コマンドセット・接続方式・はい / いいえ など**選択肢のある列**は、選んだセルの **▼**（またはダブルクリック・Space・F4）で一覧から選べます。複数のセルを選んでいれば、まとめて同じ値が入ります（v1.7.4）
- **Ctrl+C / Ctrl+X / Ctrl+V は Excel と相互**にタブ区切りでコピー・貼り付けできます。最終行を越えて貼った分は新しい行になり、
  1 つの値を範囲に貼ると全部に入ります。「はい／いいえ」「SSH／Telnet／シリアル」「パスワード／公開鍵」などは日本語・英語どちらでも読みます
- **Ctrl+D** で上の値を下へ、**Ctrl+R** で左の値を右へ。選択の右下の **■ をドラッグ**すると、末尾が数字の値は連番（`core-sw1`→`core-sw2`、
  `192.0.2.10`→`.11`）、それ以外はコピーで埋めます（Ctrl を押しながらで連番とコピーを入れ替え。最終行より下へ伸ばすと行が増えます）
- 表の下には**いつも空行が 20 行**あり、そのまま打ち込んだり貼り付けたりできます（打ち込むとその行にグループ・SSH などの既定値が入ります。何も入れていない空行は保存されません）
- **行の操作**は表の上のボタン（上に行を挿入／下に行を挿入／行をコピー／コピーした行を挿入／行を複製／↑ 上へ移動／↓ 下へ移動／行を削除）、
  右クリック、キー（Ctrl+Shift+＋ で挿入・Ctrl+－ で削除・Alt+↑↓ で移動）のどれでもできます。行番号にマウスを乗せると出る **＋** でその下に 1 行挿入します。
  「行をコピー」した行は隠している列（パスワードなど）も含めて「コピーした行を挿入」で挿入でき、Excel からコピーした行も挿入できます
- **Ctrl+X で切り取ってから貼り付けると移動**です（Excel と同じく、貼り付けた時点で元のセルが空になります。コピー・切り取りした範囲は点線で囲まれ、Esc で取り消し）
- **Ctrl+Z / Ctrl+Y** で元に戻す・やり直し、**Ctrl+F / Ctrl+H** で検索・置換（選択範囲だけ・大文字と小文字を区別・セル全体が一致も選べます）
- 見出しの **▾** で昇順・降順の並べ替え、**値の一覧から選んで絞り込み**（Excel のフィルター）、列を隠す。並べ替え・絞り込みは表示だけですが、
  「この並び順で確定」でその順番を表の順番（保存すると機器の並び順）にできます。絞り込んだあとに編集・追加した行は、絞り込みをかけ直すまで表示されたままです
- 見出しの境目をドラッグで**列幅**を変更（ダブルクリックで内容に合わせる・この PC に記憶）。Shift+Space で行、Ctrl+Space で列を選択。
  ■ を**ダブルクリック**すると最後の機器の行まで埋めます。入力中はその列にある値が候補に出ます。選択中のセル数は表の右上に出ます
- 編集の動きも Excel と同じです: 文字を打ち始めたセルは矢印キーで確定して隣へ、F2・ダブルクリックで入ったときは矢印キーで文字の中を動きます（編集中に F2 で切り替え）。
  日本語入力の変換中の Enter・矢印は変換に使われます。Ctrl+矢印は値の続く端で止まり、Ctrl+End は最後の機器の行へ。右クリックの「貼り付け」も Ctrl+V と同じです
- `=` `+` `-` `@` で始まる値は、Excel で数式として実行されないよう先頭に `'` を付けてコピーし、表へ貼り戻すときに外します。
  そのため、外から貼る値が `'=` `'+` `'-` `'@` `''` で始まるときは、先頭の `'` が 1 つ外れます（パスワードなどはそのあと編集で直してください）
- Excel との違い（意図的）: 隠した列には貼り付けません（表示している列に順に入ります）。絞り込み中の貼り付けは表示している行にだけ入ります。
  数式・書式・Ctrl+クリックの飛び飛び選択・選択枠のドラッグ移動はありません
- 「表の編集を終える」は左上と右上にあります
- パスワード類は ●●●● で表示し、「パスワードを表示」を押している間だけ平文で表示・コピーします（ロックすると伏せ字に戻ります）
  この表の中でのコピー・貼り付け（行のコピーなど）は伏せていても本当の値で貼られます。伏せている間に外から空のパスワードを貼っても、今のパスワードは消えません（消すときは Delete か、表示してから）
- 変更したセルは黄色、新しい行は緑、**エラーのセルは赤枠**（マウスを当てると理由）で、入力するたびに確認されます
- **保存するまでは下書き**です。下書きはパスワードを含むため vault に暗号化して自動保存され、タブの切り替え・ロック・終了でも消えません。
  下書きがある間は機器一覧・グループ一覧・実行タブに「下書き n 行（未反映）」と出ます（一括実行や接続は保存済みの内容で行います）
- 「保存」（Ctrl+S）で件数を確認して保存します。エラーがあると「エラーのない行だけ保存（エラー行は下書きとして保存）」「すべて保存しない（編集に戻る）」
  「キャンセル」を選べます。表を開いてから機器の編集画面などで同じ機器が変更・削除されていた場合は、どちらを残すか選べます
- 表の行の順番が機器の並び順として保存されます。「下書きを破棄」で保存済みの内容に戻せます

**入力チェック**: 保存時に、IPアドレス形式（例: `192.168.1111.1` のような不正値は拒否）・
必須項目・ポート範囲などを検証し、問題があればエラーを表示して保存しません（機器名・IP アドレスの誤りは、その欄の下に表示され、その欄にカーソルが移ります）。

**グループ選択画面**: 「機器一覧」タブを開くとまずグループのカードが並ぶ画面が出ます（詳しくは下の「機器グループ（会社単位）と対象選択フロー」）。
機器が 1 台も無いときは、この画面に「はじめかた」として 3 ステップ（グループを作る → 機器を追加 → 実行）の案内が出ます。
実行タブの「グループで対象を選択…」でも同じグループから選び、そのグループの機器だけを実行対象にできます。

**グループ既定の認証情報**: グループ内の機器が同じユーザー名・パスワードでログインする場合は、
グループの機器一覧上部の「グループ既定の認証情報…」で一度だけ登録し、機器側は編集画面の
「認証情報の扱い」を**「グループ既定を使う」**にします（一覧に「既定」バッジが付きます）。
同じグループでもパスワードが違う機器は**「この機器に個別に設定」**のままにすれば、その機器だけ自分の
認証情報でログインします。ダイアログの「全機器を切り替える」で一括切替もできます（1 回の保存で済むので、300 台でもすぐ終わります）。

### 3. 一括実行（「実行」タブ）

- 「グループで対象を選択…」で実行するグループを選び、表のチェック（実行対象）を入れた機器が対象です
  （機器一覧で見ていたグループで開きます。グループを削除して**グループ未設定**になった機器も「（グループ未設定）」で選べます）。
  列見出しで並び替え、表の上の絞り込み（文字・拠点・状態）で表示を絞れます（文字は機器名・IP のほか OS タイプ名にも一致。状態「実行中」は接続中・ログイン中・保存中も含みます）。**絞り込み中は表示中の機器だけが実行対象**（非表示でチェック済みの台数を警告表示）。
  コマンドセット列は、割り当てたセットが削除されて無くなっている機器では「X（存在しません）」と警告色で出ます。
- **作業タイミング**（指定なし / 作業前 / 作業中 / 作業後）を選んで実行すると、ログのフォルダ名と
  ファイル名に `_before` / `_work` / `_after` が付き、「実行履歴」タブで作業前と作業後を比較できます
  （付与する文字列は「設定」で変更できます）。実行前の確認には選んだ作業タイミングが大きく色分けで出て
  （作業前=青・作業中=橙・作業後=緑）、ボタンも「▶ 作業前として実行」のようになります。「指定なし」のときは
  比較で自動選択されない旨を警告色で表示します。
- **今回だけのコマンド**: 「コマンド: 機器ごとの設定どおり」の選択で、**この実行だけ**全機器に別のコマンドセットを使えます
  （機器の割り当ては変わりません）。「今回だけ入力…」を選ぶと、その場で 1 行 1 コマンドで打ったコマンドを流せます
  （待機は各 1 秒・保存されません）。表のコマンドセット列が青字で「今回のみ」を示し、実行前の確認にも表示されます。
- **失敗した機器の行の「編集」**（v1.7.7）: 実行表の各行から機器の編集画面を直接開けます。認証失敗や踏み台の設定をその場で直し、
  「↻ 失敗のみ再実行」で再実行できます（機器一覧タブとの往復が不要）。
- **📂 この実行のフォルダ**（v1.7.7）: 一括実行が終わると見出し右に出るボタンで、その実行のログが入ったフォルダ（日時フォルダ）を開きます。
  状態を「エラー」で絞り込んで「▶ 表示中の n 台を実行」したときは、成功済みの行の「完了」とログ表示が消えずに残ります。
- **⚡ 接続確認のみ**: 接続とログインだけを行い、コマンドは送らずログも残しません（認証情報・到達性の事前確認）。
  v1.7.7 から確認ダイアログなしで始まります（絞り込み中、または「踏み台: 使わない」のときだけ確認）。
  繋がらなかった機器は、エラーの末尾に**機器（または踏み台）の最後の表示**が付きます（例: `（機器の最後の表示: "ops@jump1:~$"）`＝踏み台のプロンプトで止まった）。手動接続に切り替えなくても、どこで止まったかが分かります。
  失敗した行の**「出力」**リンクで、機器が表示していた内容そのもの（パスワードは伏せ字）をその場で確認できます（接続確認のみではログを残さないため。ファイルには保存しません）。
  OS タイプ設定の編集画面の **「保存して接続確認へ」** を押すと、保存したうえで実行タブがその OS タイプの機器に絞り込まれた状態で開くので、直したプロファイルをそのまま「⚡ 接続確認のみ」で試せます（v1.7.7）。
- **メッセージ列**（v1.7.7）: 完了した行はログファイル名だけを表示します。エラーは 2 行までで折り返し、クリックすると全文が開きます。
  繋がらない機器のエラーは「接続できません（応答がありません）…」「接続を拒否されました…」「ホスト名を解決できません…」「ネットワーク経路がありません…」のような日本語の文で、元のエラーは括弧内に付きます。
  enable パスワードが通らなかったときは「enable（昇格）パスワードが受け付けられませんでした…」、ページャ解除コマンドが機器に拒否されたときは失敗ではなくその行の「警告」になります。
  実行中に接続が切れたときは、タイムアウトを待たずに「機器との接続が切れました」ですぐその機器を止めます。シリアルの COM ポートが使えないときも
  「COM3 は他のプログラム（Tera Term・別の対話接続など）が使用中です…」「COM3 が見つかりません。USBシリアル変換ケーブルの接続と…」のように日本語で出ます。
  ログを書き込めないとき（ネットワークドライブの切断・権限・空き容量）は、**機器に接続する前に**止まります（「ログを書き込めないため、機器には接続しませんでした…」）。
- **踏み台: 使わない（直接接続）**（v1.7.3）: 踏み台のある機器がいるグループでは、ツールバーで「踏み台: 機器の設定どおり／使わない（直接接続）」を選べます。
  「使わない」にすると、**この実行と、この表の「接続」だけ**、踏み台を通らずにこの PC から機器へ直接接続します（現場で機器のネットワークにつないでいるときなど）。機器の設定は変わらず、実行前の確認に「直接接続します」と出ます。
- **設定変更コマンドの事前警告**: コマンドセットに `conf t` / `write` / `reload` / `no …` /
  `erase` など機器を変更するコマンドが含まれていると、実行前にそのコマンドを列挙した警告が出て、
  「変更を伴うことを理解したうえで実行します」にチェックしないと実行できません（対象の機器名は 10 台まで列挙し、残りは台数で示します）。
- **機器に拒否されたコマンドの警告**: `% Invalid input` / `Invalid command` / `command not found` などが返ったコマンドは、
  その機器を「完了」のまま状態列に**「警告 n」**を付け、メッセージ列に「コマンド → 機器の応答」を表示します（実行履歴にも残ります）。
  作業前ログの取り漏れにその場で気づけます。
- **確認を求めるコマンド**（`copy run start` の `Destination filename [startup-config]?`、`clear counters` の `[confirm]` など）は、
  OS タイプの「確認への自動応答」で答えます（Cisco IOS / ASA は既定で Enter＝機器の既定値で進む）。応答が無い質問で止まった
  コマンドは、その機器の残りのコマンドを送らず失敗にします（状態の分からない機器に続きを打ち込まないため）。
- 「▶ 一括実行」で全対象へ並列接続。各機器の状態（順番待ち / 接続中 / ログイン中 /
  実行中 / 完了 / エラー）がリアルタイムに表示されます。実行中は機器ごとに
  完了数/全体数と「残り 約n秒」（その機器の残りコマンド全部が終わるまでの概算）が出ます。
- ログは機器ごとに**届いた順に書きながら保存**します。各行の「ログ表示」は接続を始めた時点から出て、実行中の機器なら自動更新（追記を追う）で開きます。終わったあとも同じファイルを開けます（検索・文字サイズ変更・全文コピー・再読込・「折り返し」）。選択した文字は右クリック（または Ctrl+C）でコピーでき、自動更新中も選択は外れません。
  その左の「画面」は、機器の画面を**表示のみのターミナル**で開きます（Tera Term マクロの実行中の窓と同じ見え方。実行中は出力を約 0.3 秒遅れで追い、「最後の出力から ◯ 秒」で止まっていないか分かります）。キー入力は機器に送りません。途中でおかしいと気づいたら、その行の「止める」でその機器だけ止められます。
  対話接続のツールバーにも「ログ表示」があり、書き込み中のログを自動で追います。
- 「ログフォルダを開く」で保存先を開きます。
- **中止**: 「■ 中止」を押すと（確認のうえ）実行中の機器は打ち切り、未実行の機器は開始しません。
  打ち切られた機器と未実行の機器は「中止」と表示され、完了済みの機器のログはそのまま残ります。
- **機器ごとの中止**: 実行中・順番待ちの行の「止める」で、その機器だけを止めます（確認のうえ。ほかの機器は続けます）。実行中なら打ち切り（ここまでのログは残ります）、順番待ちなら開始しません。止めた機器は「↻ 失敗・中止のみ再実行」で取り直せます。
  その後は「▶ 一括実行」（最初から全部）・「↻ 失敗・中止のみ再実行」（完了済みはそのまま）・
  「✕ 結果をクリア」（表を実行前の状態に戻す）から選べます。再実行は**前回の実行と同じ内容**（グループ・作業タイミング・コマンドの選択）で行い、
  設定変更コマンドが含まれていれば最初の実行と同じ警告が出ます。
- コマンドセットが割り当てられていない機器はログインだけで終わるため、実行前の確認に台数と機器名が出ます（表のコマンドセット列も警告色）。
- ロック（手動・自動）しても、解除すると実行タブの結果・「再実行」ボタン・選んでいたグループはそのまま戻ります。
- 一括実行中は Windows の自動スリープ（一定時間操作がないときのスリープ）を止め、実行が終わる（完了・中止・エラー）と元に戻します（画面の消灯は止めません）。
  ノート PC の蓋を閉じる・手動でスリープにする操作は止められないので、長い実行中は蓋を閉じないでください。
  蓋を閉じるとスリープする設定のノート PC では、実行中の実行タブにその旨が出ます（Windows の設定を読むだけで、変更はしません）。
  画面ロックでは止まりません。スリープした場合は、起きたあとに途中から再開したり取り直したりはしないので、止まった機器は「失敗のみ再実行」で取り直してください
  （電源設定で「蓋を閉じたときの動作」を「何もしない」にする方法もあります）。
- 一括実行中に × で閉じようとすると「PalaTerm を終了すると実行が止まります」と確認します（キャンセルなら実行は続きます）。終了するときは「■ 中止」と同じく実行を止め、
  その回の記録（`palaterm-run.json`）を書いてから閉じるので、実行中だった機器のログはそこまでの分が残り、その回は実行履歴タブにも出ます。
  スリープ・電源断で止まったときもログはそこまでの分が残りますが、実行履歴タブにはその回は出ません。
- 一括実行の最中に「ロック」しても実行は続き、解除すると進捗の表示と「■ 中止」に戻れます（ロック中に終わっていれば結果が表示されます）。
- コマンドセットや一式の読み込み、コマンドの保存では、改行・タブなどの制御文字を含むコマンドを受け付けません（画面では空白に見える改行に、別のコマンドを隠せるため）。
- 確認を求められたまま止まったコマンドは、エラーに機器の最後の表示が付きます（自動応答に登録するか、コマンドタイムアウトを延ばすかの目安）。

### 4. 実行履歴と作業前後の比較（「実行履歴」タブ）

一括実行のたびにログフォルダ内の `日時[_グループ][_作業タイミング]/`（既定のフォルダ名） に `palaterm-run.json`（機器ごとの成否・
ログファイル名）が残り、「実行履歴」タブに新しい順で並びます。▸ で機器ごとの結果と「ログ表示」、
「フォルダ」でエクスプローラーを開けます。開いた一覧では失敗・中止の機器が先に並び、11 台以上の実行では
「失敗・中止の n 台だけ表示」のチェックで絞れます（v1.7.7）。

**他で取ったログ（外部フォルダ）**: PalaTerm 以外で取った過去の案件のログも、フォルダごと `logs\` の**直下**に置くと「外部」バッジ付きで一覧に並び、
A / B / 作業中のどれにも選べます（v1.7.8。フォルダ名に決まった語は要りません）。対象は `logs\` 直下のフォルダだけで、その中のフォルダ（古い実行を退避したフォルダなど）は見ません（v1.7.9）。
フォルダ名に `前` / `中` / `後`、`作業前` / `作業中` / `作業後`、`変更前` / `変更後`、`before` / `after` / `during`、`pre` / `post` / `work`、設定した作業タイミングの語があれば、
A / B / 作業中の既定の選択に使います。機器名はファイル名から日付・時刻・作業語を除いたもの（`sw01_前_20261019.txt` と `sw01_後.log` はどちらも `sw01`）として
A と B を突き合わせ、完全に一致しない場合は先頭が同じ名前同士（`sw01` と `sw01_HQ`）を組にして「↔」で示します。`作業前ログ` のように作業語に続く語や機器名にくっついた作業語（`sw01作業前`）、IP アドレスの名前（`192.0.2.1_20261019_1150.log` は `192.0.2.1`）、`2026年10月19日` の形の日付にも対応します（v1.7.10）。突き合う機器が無いときは、A と B で読み取った機器名を数件ずつ表示します。拡張子は .txt / .log / .out / .cfg / .conf など（画像や Excel は数えません）。

**比較**: 2 回の実行を A（作業前）/ B（作業後）に選んで（選択肢はログフォルダ内の実行フォルダ名）「比較する」と、同じ機器名のログ同士を突き合わせ、
機器ごとに「差分なし／差分あり（追加・削除行数）」が出ます。A または B で失敗した機器は「A のみ」に隠れず、
**先頭に赤で「A で失敗」のように**エラーの内容と A / B のログへのリンク付きで並びます（v1.7.7）。
B には A より後の最新の「作業後」が自動で入り、B が A より古いときは警告が出ます。「差分を開く」で WinMerge 風の別ウィンドウ
（左 A・右 B、変更行は黄・A のみ赤・B のみ緑、位置バー、前後の差分へ移動、検索は Ctrl+F、Esc で閉じる）が開き、
「時刻・カウンタの違いを無視」（既定オン: `show clock` の時刻や uptime、トラフィック量の違いを
差分扱いにしない）と「差分の周辺だけ表示」を切り替えられます。
「作業中（任意）」に A と B の間の作業（作業中の一括実行または対話接続）を選ぶと、作業中のログから
投入した設定コマンド行を抜き出し（show 系・exit/end・write 等のほか、機器に拒否された行＝打ち間違いや `% Invalid input`、`?` ヘルプや Tab 補完の途中で再表示された行も除外）、作業後のログに 1 件ずつあるか照合します
（`no …` は対象行が消えていれば反映）。インタフェース等の中で打った行は、作業後ログのそのブロックの中で探します。
機器は打った文字のままではなく自分の書式で設定を保存するため、次の違いは「反映」として照合します（v1.7.11）:
省略形（`int gi0/1` → `interface GigabitEthernet0/1`、`sw mo acc` → `switchport mode access`）、
暗号化されたパスワード（`password x` → `secret 9 …`・FortiGate の `ENC`）、まとめられた VLAN 一覧
（`allowed vlan add 30` → `allowed vlan 10,20,30`）、機器が語を足した行（`spanning-tree portfast` → `… portfast edge`。作業で増えた行に限る）、
FortiGate の引用符、Juniper の `{ }` 形式（`set` 行に直して照合・`edit` 中の相対 `set` にも対応）。
説明文（description・name 等）と数値・IP は打ったとおりでないと一致しません。
ログからは判定できない行は「？ 要確認」とし、未反映には数えません: 別のブロックにある行、設定に残らないコマンド
（`interface range`・`crypto key generate`・`clock set`・`banner` 等）、表示されない既定値（`duplex auto` 等）、
作業前後で同じ暗号化文字列のパスワード、作業後のログに設定の表示が無い場合。
機器ごとに「✅ n 件すべて反映／⚠ m / n 件が未反映」と各行の ✓ ✗ ？（照合に使った行は「→」の後に表示）、
全体に「作業中に設定した内容（c 件）が、作業後に全 n 台で反映されています」等の結論が出ます。
作業後の取得には show running-config 相当を含めてください。
同じ作業の中で打ち直した行（`shutdown` → `no shutdown`、IP アドレスの打ち直し等）は、前の行を「↷ 後の行で取り消し・上書き」とし未反映に数えません
（`ntp server`・`ip route` など足していく設定は除く）。接続が切れて作業ログが複数のフォルダに分かれたときは、A と B の間にある同じグループの作業ログを合わせて照合します。
作業前→作業後で変わった設定のうち、作業中に打った行で説明できないもの（別のポートを変えてしまった、ほかの人の変更、機器が自動で加えた行など）は
機器ごとに「⚠ 作業外の変更 n 行」として表示します（show running-config 等の出力どうしを比べます）。
`Current configuration : n bytes`・`! Last configuration change at …`・`ntp clock-period`・FortiGate の `#conf_file_ver`・Junos の `## Last commit` は
取るたびに変わるため差分に数えません。結果は未反映・作業外の変更・要確認のある機器から順に並び、それらだけに絞り込めます。
「結果をコピー」で Excel や作業報告に貼れる形（タブ区切り）、「CSV に書き出す」で `export\compare` に CSV を出せます（v1.7.11）。
AlaxalA の未保存を示す `!` 付きプロンプト（`!sw(config)#`）も打った行として読み取り、画面端の折り返しで行の途中に空白が入った行（`ac tion`）も、
空白を除いて同じなら反映として照合します。AlaxalA の `#Last modified by …` の行は差分に数えません（v1.7.12）。
`interface range` の中で打った行は各インタフェースで照合し（全部にあれば反映）、`no interface …` で消したブロックの行は作業外の変更に数えません。
接続が切れて分かれた作業ログはセッションごとに読み取ります。作業前・作業後のログに設定の一覧が複数（show running-config と show startup-config 等）あるときは、
最後の running-config 全体の一覧どうしで作業外の変更を探します（v1.7.13）。

### 5. 予約（「予約」タブ）

決まった日時に、自動で一括実行してログを取ります（show 系の取得専用）。よくある使い方は次の 3 つです。

- **定期バックアップ**: 毎日 03:00 に show running-config など（コマンドセット）。
- **今から一定間隔で状態を取る**（障害調査・作業中の監視）: 「保存したらすぐ」から 10 秒おきに 20 回、その場で入力した show コマンドを。
- **夜間作業の前後**: 作業前・作業後を 1 回ずつ取り、実行履歴タブで比べる。

作り方は「予約」タブの「＋ 予約を追加」。編集画面は上から順に答えるだけです（名前は内容から自動で付きます）。

- **① いつ実行しますか**: 1回だけ（日付＋時刻）／毎日／毎週（曜日は複数可）／一定間隔で繰り返す。日付はカレンダーから、時刻は時・分・秒のプルダウンで選び、過去の日時は選べません。
  1 つの予約は 1 つの日時ルールです（別の時刻は別の予約にします）。
- **一定間隔で繰り返す**: 開始は「保存したらすぐ」（既定）か「日時を指定」。間隔は 10 秒〜7 日（秒・分・時間）。
  **終わり**は「◯ 回で終わる」（既定 10 回）／「◯月◯日 ◯時まで」／「止めるまで続ける」から選びます。
- **② どの機器で実行しますか**: グループを選び、機器をチェック。**絞り込み**（機器名・IP・拠点・役割）、「表示中をすべて選択／解除」、
  「選択中だけ表示」、**Shift＋クリックで範囲選択**ができ、「選択中 ◯ / ◯ 台」が出ます。
- **③ 何を実行しますか**: 「コマンドセットから選ぶ」か「コマンドを直接入力する（1 行に 1 コマンド）」。
- 一覧の **「複製」** で、同じ日時・機器・コマンドが入った**未保存の新しい予約**の編集画面が開きます（別のグループに同じ予約を作るときなど・v1.7.7）。「保存」するまで予約は作られず、キャンセルすれば何も残りません。
  動いている一定間隔の予約を複製すると、複製も保存した時点から動き始め、「止めるまで続ける」の選択も引き継ぎます。
- 予約が名指しする機器を削除したとき（1 台ずつ・一括削除・表で編集・一覧の取り込みの削除）、別のグループへ移したとき（編集画面・一括変更）、予約のグループを削除したとき
  （グループ未設定の機器を対象にした予約も。削除したグループの機器が加わるため）は、その予約は自動で**停止**し、トーストで知らせて実行記録に理由が残ります
  （後から同じ名前のグループや機器ができたときに、別の機器へ無人で実行しないため）。「▶ 再開」で動かせます。
- 対象の機器の一部が見つからない回は、残りの機器で実行し、実行記録に「見つからない機器を外して実行しました: …」と残ります。
- 予約が予定どおりに動かなかったとき（エラー・拒否・停止・見逃し・スキップ）は、トーストとトレイの通知で知らせ（同じ予約の同じ種類は 10 分に 1 回まで）、
  予約の一覧の状態の下に「⚠ 直近: 見逃し」のように出ます（押すと実行記録を開きます）。
- **詳細設定（ふだんは変更不要）**: 作業タイミング（夜間作業の前後を比べたいときだけ「作業前」「作業後」）。
- **予約の一覧**: 状態（有効・実行中・順番待ち・停止中・終了）、「どの機器に・どのコマンドを・いつ」、次の実行と「あと ◯ 回」が出ます（タブ上部の「次の実行」には予約の名前も出ます）。
  **「⏸ 止める」**で止まり（実行中ならその回も中止）、**「▶ 再開」**でまた動きます。「今すぐ実行」で 1 回だけ試せます。
  もう実行されない予約は「終了」と出て、**「終了した予約をまとめて削除」**で片付けられます（実行記録とログは残ります）。
- 一定間隔の予約で、前の回の実行がまだ終わらないうちに次の時刻が来たときは、重ねて実行せずその回をスキップして記録します（回数には数えます）。
- **設定を変更するコマンドを含むセットは予約できません**（保存時と実行のたびに確認し、含まれていれば実行せず「拒否」と記録）。
- **NEC IX の注意**: 標準の NEC IX プロファイルは、ページャ解除のために `svintr-config` で設定モードに入ります（`terminal length 0` と `show running-config` が設定モードでしか使えないため）。
  `svintr-config` は、ほかの管理者が設定モードに入っていても奪い取り、その人を運用モードに戻します。無人で動く予約では特に、これを避けたい場合は OS タイプ設定で NEC IX の「ページャ解除コマンド」の `svintr-config` を `configure` に書き換えてください
  （`configure` は誰かが設定モード中なら `% CONFIG process is occupied.` で失敗し、その回のページャ解除と show running-config が取れないことがあります）。
- 予約は **PalaTerm が起動している間だけ**動きます。予約があるときに × で閉じるとタスクトレイに残ります
  （クリックで再表示・右クリック →「終了」で終了。Windows 11 ではアイコンが通知領域の「^」の中に入ります）。
  トレイのアイコンにマウスを乗せると、実行中の予約（進み具合付き）か次の実行時刻と予約名が出ます（右クリックメニューの先頭にも同じ内容）。**ロック中も実行**します（対象機器の認証情報はロック中もメモリに残します。ファイルには書きません）。
- **スリープ中**は予約の 90 秒前に PC を起こして実行します（電源オプションの「スリープ解除タイマーの許可」が有効であること）。
  休止状態・シャットダウン・PalaTerm の終了中は動きません。
- 予約タブの上に、この PC で予約がどう動くかが 1 行で出ます。「ⓘ この PC は、スリープすると予約が止まります」と出る PC
  （スリープ解除タイマーが無効、またはモダンスタンバイ）では、その下の **「放置してもスリープさせない」** をオンにすると、
  有効な予約が残っている間は放置による自動スリープを止めます（画面ロック・画面オフはそのまま）。Windows の電源設定は書き換えず、
  PalaTerm が動いている間だけ Windows に「スリープしないで」と頼む仕組み（`SetThreadExecutionState`）なので、オフにする・予約がなくなる・
  PalaTerm を終了すると元どおりです。蓋閉じ・手動スリープは止められません。
- 予約を保存する前に「いつ・どの機器に・何を」を確認する画面が出ます（「戻って直す」で編集に戻れます）。繰り返しの予約は、
  毎回ではなく、失敗したときと最後の回だけ知らせます。
- 実行できなかった回は「見逃し」として記録し、さかのぼっては実行しません。ほかの一括実行と重なったら順番待ちし、30 分を過ぎたらスキップします。
- PalaTerm を起動し直したあとは、**ロックを解除するまで予約は動きません**（ロック画面にその旨が出ます）。終了していた間とロック解除までの間に来た回は、
  解除したときに「見逃し」として記録します（予約ごとの最後の確認時刻を `data\schedule-checked.json` に保存。予約の ID と時刻だけです）。
- PalaTerm は 1 つのフォルダにつき 1 つだけ起動します（2 つ目を開くと、動いている方の窓が出ます。別のパス・別の PC から開いたときは上の「二重起動」）。
- 予約のログは、予約ごとに 1 つのフォルダ（既定: `日時_グループ_reserve`。reserve は設定の「ログ名に付く作業タイミングの語」で変えられます。日時は初回）にまとめて入ります。繰り返しても毎回新しいフォルダは作りません。実行履歴には予約 1 つが 1 行で「予約」の印と「◯ 回分」付きで並び、▸ で各機器の最新の回の結果が見られます。予約タブの「予約の実行記録」には実行・見逃し・スキップ・拒否・エラーが残ります
  （`data\schedule-log.json`。機器名・時刻・件数だけで、認証情報は含みません）。

## 対話接続（1台にログインして手動操作）

機器一覧または**実行タブ**の各行の **「接続」** ボタンで、その1台にログイン・enable昇格・
ページャ無効化まで自動で済ませた状態の端末が、**本ツールとは独立した別ウィンドウ**（タスクバーにも
別表示）で開きます。**複数機器へ同時に別ウィンドウで接続**でき、各ウィンドウは四辺・四隅から
自由にリサイズできます（表示列数も追従。変えた大きさは次の窓にも使われ（`%LOCALAPPDATA%\PalaTerm\term-window.json`）、
2 枚目以降は少しずらして重なるように開きます）。ウィンドウのタイトルは「機器名 - アドレス」で、切断後は「切断」、失敗時は「接続失敗」が付きます（踏み台経由なら画面上部に「踏み台 n 段経由」）。踏み台経由でも自動で通り抜けます。**自動ログインの間も機器（踏み台）の表示がそのまま流れる**ので
（見るだけ・キー入力はログイン後から。ログイン中にキーを打つと「自動ログイン中のため、キー入力は機器に送られません。手で操作するときは『手動に切り替え』」と 1 回案内します）、繋がらないときに「踏み台のプロンプトで止まっている」「Password: で止まっている」などが待っている間に分かります。対話接続の内容も
**ログファイルに保存**されます（切断時に保存先を表示）。`exit` またはウィンドウを閉じて終了します
（接続中に × で閉じると「切断して閉じますか？」と確認します）。
- **再接続**: 切断後は上部の「再接続」ボタン（または Enter キー）で同じ機器にもう一度接続します（機器の reload 後など）。
  ホストキーの確認（「ホストキーが前回と異なります」）を閉じたあとは、「再接続（ホストキーを確認）」（または Enter キー）で確認をもう一度出せます。
- **スクロールバック**は 10,000 行（Tera Term の既定と同じ）。長い `show running-config` も Ctrl+Shift+F（または「検索」ボタン）で探せます（Ctrl+F は機器へ送られます・v1.7.7）。
- **SSH の keepalive**: 30 秒ごとに送るので、ファイアウォール越しに放置しても切れにくくなっています。
- **ブレーク信号**（シリアル接続のみ）: 「ブレーク」ボタンまたは **Alt+B**（Tera Term と同じ・シリアル接続のときだけ。SSH/Telnet では Alt+B は機器の「1 単語戻る」に使われます）。Cisco の起動中に送ると ROMMON に入れます（パスワードリカバリ）。
- **ロック**: 本体の「ロック」を押すと対話窓もロック画面になります（接続は保たれ、マスターパスワードで戻ります）。対話窓は自分の操作が
  「アイドル時の自動ロック」の時間なければ自分でロックします（1 分前に画面にその旨が出ます）。**本体を終了すると対話窓も閉じます**（開いていれば終了前に確認します）。

**自動ログインなしで開く（シリアルでの初期キッティングなど）**: 工場出荷状態の初期設定ダイアログ、パスワード未設定の機器、
初回ログイン時のパスワード強制変更など、OSプロファイルが想定しない画面では自動ログインが進みません。そのための入口が 3 つあります。
- 「接続」を **Shift+クリック（または右クリック）** → 回線（シリアルポート / SSH / Telnet）を開くだけで**何も自動では打たない**端末が開きます（Tera Term で普通に接続したときと同じ状態。踏み台がある機器では 1 段目だけ接続。踏み台の通り方が SSH トンネルなら対象機器まで接続）。
- 対話窓の接続中に出る **「手動に切り替え」** ボタン → 自動ログインをその場で打ち切り、機器が出している画面のまま手で操作に入ります（タイムアウトを待たずに済みます）。
- 自動ログインに**失敗しても回線は切らず**、画面に機器の応答とエラーを表示したうえで上部に **「手動で続ける」／「切断する」** のバーが出ます。「手動で続ける」で、その画面にそのまま手で答えられます。
いずれもログは通常の対話接続と同じく保存されます。

貼り付けは **Ctrl+V**（Shift+Insert / Ctrl+Shift+V も可）、または **Alt+V**（Tera Term の「貼り付け<CR>」相当）、
**右クリック**（「設定」で無効化・メニューで確認に変更可）、ツールバーの「貼り付け…」。**1 行だけなら確認なしでそのまま貼り付け**、Enter は送りません（内容を見てから自分で Enter。Alt+V のときだけ Enter も送ります）。
**2 行以上**は Tera Term と同様に**貼り付ける内容の確認が別ウィンドウ**で開き（端末の手前・移動やサイズ変更可）、
内容を見て（必要なら編集して）「貼り付け」または Enter で送ります（「最後に Enter を送る」は既定でオン。切り替えた状態は次回以降も引き継がれます。Alt+V のときは常にオン）。
Windows のクリップボード履歴（Win+V）から選んだ項目も同じ確認を経ます。複数行は各行末が Enter として送られます。
対話接続・貼り付けの確認・ログ表示・差分の各ウィンドウは、**開いた元のウィンドウの上（同じモニタ）**に開きます（デュアルモニタで本体をサブモニタに置いていても、そちらに出ます）。
コピーは Tera Term と同じく**マウスで範囲を選択するだけ**で自動的にクリップボードへ入り、バーに「コピーしました」と出ます
（ダブルクリックで単語選択）。Ctrl+C はコピーではなく機器への中断（^C）送信です。
ツールバーの「ログフォルダ」でこの接続のログが入っているフォルダを開けます。対話接続のログは Tera Term と同様に**画面に出た内容がそのままリアルタイムでファイルへ書かれます**
（既定ではそのまま記録。「設定」の「ログ内のパスワードをマスクする」をオンにすると、機器のパスワードが現れた箇所を `****` に置き換えて保存します）。ツールバーの「ログ停止」で記録を止め、「ログ開始」で同じファイルに続きを記録します（停止・再開の時刻がファイルに記されます）。
**文字サイズ**は「A−」「A＋」・Ctrl+ホイール・Ctrl+「+」「−」で変更（Ctrl+0 で既定に戻す・次回も保持）、
**検索**は Ctrl+Shift+F または「検索」ボタン（Enter で次・Shift+Enter で前・Esc で閉じる。Ctrl+F は機器に送られます）。

### 並べて接続・同時入力（複数台に同じコマンドを打つ）

機器一覧で機器にチェックを入れ、上に出るバーの **「並べて接続」** を押すと、選んだ機器（最大 16 台）の対話窓がまとめて開き、
本体のあるモニタいっぱいに**重ならないよう並びます**（2 台なら左右、4 台なら 2×2、9 台なら 3×3。半端な最後の段は横いっぱいに広げます）。
Tera Term で 1 台ずつ接続してから［ウィンドウ］-［左右に並べて表示］するのと同じ配置を、ボタン 1 つで作ります。
**実行タブ**のツールバーの **「並べて接続（n台）」** でも同じことができます。チェックした実行対象の機器（絞り込み中は表示中の機器だけ。一括実行と同じ範囲）を開き、「踏み台: 使わない」を選んでいればその窓も踏み台を通らずに接続します。

各窓のツールバーの **「同時入力」** をオンにすると、**どれか 1 つの窓で打ったキーが、同時入力オンのすべての窓に送られます**
（Tera Term の［コントロール］-［ブロードキャストコマンド］のリアルタイムモードと同じ）。
並べて開いた窓は**既定では同時入力オフ**で始まります（必要な窓だけ自分でオンにします）。「設定」タブの「並べて接続の同時入力」で、**最初からオンで開く**ようにも切り替えられます。
- 同時入力中の窓は**オレンジの枠**で囲まれ、ツールバーに「同時入力中（3 / 4 台）」と出ます（オンの窓 4 台のうち、いまキーを受け取れる窓が 3 台）。
- **ログイン中・切断中・ロック中の窓には送りません**（受け取れる台数に数えません）。
- 1 台だけ違うコマンドを打ちたいときは、その窓の「同時入力」を押してオフにします。オフの窓で打ったキーはその機器にだけ送られ、ほかの窓からも届かなくなります。
- 1 台ずつ「接続」で開いた窓は設定に関係なく**オフ**で始まります（前から開いていた無関係な窓に勝手に入力が届くことはありません）。オンにすれば参加できます。
- 貼り付けも同時に送られます。同時入力中は **1 行でも（右クリックの貼り付けでも）必ず確認ウィンドウ**が開き、「同時入力中: この内容はほかの n 台の窓にも送られます」と出ます。1 行の貼り付けは同時入力オフのときと同じく、Enter は送らない状態で開きます（「最後に Enter を送る」がオフ。Alt+V のときだけオン）。確認ウィンドウを**同時入力オフで開いたときは、あとでオンにしてもほかの窓へは送りません**（開いたときの表示どおり）。
- ほかの窓から届いた入力も、その窓の操作として数えます（打っていない窓が「アイドル時の自動ロック」でロックされ、途中から同時入力に加わらなくなることはありません）。
- マウスに対応した画面（vim・htop など）でのクリックやスクロールの信号は、その窓の機器にだけ送り、ほかの窓へは送りません。
- 送るのは打ったキーそのままです。Tab 補完・`?`・`--More--` のスペースなどは各機器がそれぞれ処理するため、機器によって画面がずれることがあります（Tera Term と同じ）。ログは窓ごとに保存されます。
- ツールバーの **「並べ直す」** で、開いている対話窓を、その窓のあるモニタいっぱいに開いた順で並べ直します（あとから 1 台追加したときなど。16 台まで。17 台目以降の窓は動かしません）。並べて接続で開けなかった機器があったときは、開いた窓だけで隙間なく並べます。

### 表示の色・端末の色

対話窓・ログ表示・画面表示（予約などの見るだけの画面）・差分の各ウィンドウは、ツールバーの **「色」** で**文字色・背景色**を変えられます
（よく使う組み合わせ 7 種のボタンと、色の指定欄・「既定に戻す」。対話窓はカーソルの色も）。変えた色はすぐ保存され、同じ種類の開いている窓にも反映されます。
「設定」タブの「表示の色」でもまとめて変えられます。保存先はこの PC です（vault・一式書き出しには入りません）。
文字と背景が近すぎて読みにくい組み合わせには警告が出ます。

既定の色は、**ログ表示が生成り色の背景**（操作中の対話窓＝黒と取り違えないため）、**画面表示が濃紺**、対話窓と差分は従来どおりの黒です。

機器ごとの **「端末の色」**（機器の編集・一括変更・表で編集・CSV の「端末の色」列。赤・橙・黄・緑・青・紫）を選ぶと、
その機器の対話窓の**背景がその色**になり、ツールバーの下に**同じ色の帯**が付きます（機器一覧の機器名の左にも同じ色の印）。
本番機は赤・検証機は緑のようにしておくと、並べた窓の中で接続先を取り違えにくくなります（「端末の色」列の無い古い CSV を読み込んでも、既存の機器の色はそのまま残ります）。

## 一覧の取り込み（他のシステムの機器一覧から登録・更新）

資産管理や監視システムなどが出力した機器一覧（Excel・CSV）を、**変換ルール**で PalaTerm の機器に変換して**グループへ取り込みます**。
サイドバーの **「一覧の取り込み」** タブ（「予約」の下）から使います。**1 ファイルが 1 グループ**になり、同じシステムから一覧を出し直したときは取り込み直すだけで更新できます。

**読めるファイル**: xls・xlsx・CSV・TSV（UTF-8 / Shift_JIS / UTF-16）。拡張子ではなく中身で形式を判断するので、
業務システムが出力する「中身が HTML の .xls」や Excel 2003 の XML 形式も読めます（Excel で開くと保護ビューの赤い警告が出るファイルもそのまま読めます）。
パスワードで保護されたファイルと、Excel 4.0 以前・xlsb 形式は読めません（Excel で xlsx に保存し直してください）。

**タブの画面**: 見出しの右に **「ルールを読み込む」**（人から受け取った変換ルールの JSON）・**「＋ ルールを作る」**・**「ファイルを選んで取り込む…」**（変換ルールが 1 つも無いうちは押せません）が並び、その下が変換ルールの一覧です。
一覧はほかの一覧と同じく、絞り込み欄（ルール名・見本ファイル名）、見出し（ルール名・項目・除外条件・最後に使った日）のクリックでの並び替え、左端の ⠿ のドラッグでの並べ替えができます。各行に **「編集」「複製」「書き出し」「削除」** があります（削除しても、取り込んだ機器はそのまま残ります）。
「複製」は元のルールの内容が入った**未保存の新しいルール**（名前は `元の名前_copy`）として編集画面を開き、「保存」するまで何も作られません（キャンセルすれば何も残りません。見本ファイル名は引き継がないので、同じ名前のファイルを選んだときは元のルールが選ばれたままです）。

### 変換ルールを作る

「＋ ルールを作る」で作ります（ルールは複数登録できます）。**見本ファイル**を選ぶとファイルの先頭が表示され、結果を見ながら作れます（見本はルールに保存しません）。
見本の表は**先頭 40 行・300 列まで**表示します（それより列が多いときは「ほか n 列」と出ます。下の項目の紐付けでは、表示していない列も含めてすべての列を選べます）。
見本のパスワードは ●●●●●● で表示します（結果の値はクリックで表示でき、表示中でも右クリックのコピーでは ● のままです）。
編集画面は **Ctrl+Enter** で保存できます。保存していない変更があるままタブを移る・ロックする・言語を切り替えるときは、破棄してよいか確認します。

新しいルールで見本ファイルを選ぶと、**見出しの名前から仮の紐付けを入れます**（見出しの行、機器名・IP アドレス・接続方式・ポート・拠点・役割・ユーザー名・パスワード・enable パスワードの列。同じ見出し名が 2 回あれば 2 つ目を 2台目に。「機種」「型番」「モデル」などの見出しがあれば、その列から **OS タイプとコマンドセットを推測する加工手順**も入ります）。
仮に入れた欄には「仮」の札が付くので、確かめて違っていれば選び直してください（選び直すとその札は消えます）。案内の帯の **「元に戻す」** で仮の紐付けを全部取り消せ、**「確認した（札を消す）」** で内容はそのままに札だけを消せます。

- **読み取り位置**: シート（名前か何枚目か）・**見出しの行（何行目）**＝項目名が書いてある行・**データの開始行（何行目）**＝普通は空欄（見出しのすぐ下。見出しとデータの間に説明の行があるときだけ指定）・**表の左端の列（AE など）**＝普通は空欄（自動。表の左にメモなど関係ない列があるときだけ指定）・結合セルの扱い（すべてのセルで同じ値 / 左上だけ）。見本の**行番号を押すと見出しの行**、**列の記号を押すと表の開始列**になります。
- **項目の紐付け**: PalaTerm の項目（機器名・IP アドレス・接続方式・OS タイプ・ユーザー名・パスワード・拠点・踏み台・GUI など）ごとに、元の**列**か**組み立て**（`{拠点コード}-{機器名称}` のように列をつなげる）を選びます。列の選択肢には **Excel の列記号**も出ます（「列(AG): 機器名称」）。列は見出しの文字で探します（見出しの名前が変わると「ファイルに無い列」と表示されます。その列から読む項目の扱いは下の「取り込み直したとき」）。
- **決まった値の項目は自動で変換**: 接続方式・認証方式・はい / いいえ・GUI の方式・ポートは、大文字 / 小文字・全角 / 半角・空白の違いを問わず、よくある書き方を PalaTerm の形式にします（例: `SSH2`・`SSHv2`・`ＳＳＨ` → ssh、`TELNET(23)` → telnet、`CONSOLE`・`コンソール` → シリアル、`YES`・`有` → はい）。
- **1 行に 2 台分（冗長構成）**: メインとバックアップのように 1 行に 2 台分が載っている一覧は、「＋ 2台目を追加（冗長構成など）」で 2 台目（名前は「バックアップ」など自由。「＋ 3台目を追加」と続けて 1 行に最大 4 台）を足し、2 台目で値が違う項目だけ元の値を選びます（選ばない項目は 1 台目と同じ値）。列が分かれていれば別の列を、`192.0.2.1/192.0.2.2` のように 1 つのセルに入っていれば同じ列に「`/` で分けて右」の加工を付けます。2 台目の機器名が空の行では 2 台目を作りません。プレビューでは 2 台目の行番号が「12-2」になり、名前の札が付きます。照合に使う列（資産番号など）を指定していると、2 台目はその値に「#2」を付けたキーで照合します。
- **加工手順**（上から順に）: **区切って残す**（区切り文字を指定・最初 / 最後で分けて左 / 右を残す・区切りが無い値は「そのまま」か「空」）、置き換え表（「Catalyst を含む → cisco-ios」など）、文字の置き換え・削除、正規表現、前後の空白を除く、全角を半角に、小文字 / 大文字に、機種から OS タイプ / コマンドセットを推測（下記）。
  例: `ops/x9/Lp2q` のように 1 つのセルに「ユーザー名/パスワード」が入っているときは、ユーザー名＝「`/` の最初で分けて左」、パスワード＝「`/` の最初で分けて右（区切りが無ければ空）」にします（パスワードに `/` が含まれていても切れません）。
- **空のときは別の列**: 列を選んだあと「＋ 空のときは別の列」で予備の列を足せます（例: IP が「PPPoE の IP」と「ゲートウェイの IP」の 2 列に分かれていて、行ごとにどちらかだけが埋まっている表）。1 つ目の列が空欄の行は 2 つ目の列の値を使い、両方埋まっていれば 1 つ目を使います。見本の結果には「（列(AJ) から）」のようにどの列から取ったかが出ます。
- **機種から OS タイプ・コマンドセットを推測**（加工手順）: 機種の値（IX2215・C2960・FortiGate 60F など）から、この PalaTerm にある OS タイプを選びます（判定できないときは既定値）。コマンドセットは、名前がメーカーと種別（Cisco と L2 など）に合うものが**ちょうど 1 つ**のときだけ選び、設定変更・保存のコマンドを含むコマンドセットは選びません。推測で入った値はプレビューに「推測」と出て、**取り込み直しでは既存の機器のコマンドセットは変えません**（新しい機器にだけ入ります）。置き換え表を推測の前に置けば、そちらが優先です。
- **空のときの既定値**: 加工したあとも空の項目を埋めます（プレビューでは「既定」の札が付きます）。
- **除外条件**: 「状態 が『撤去』を含む」のような条件に 1 つでも当てはまる行は取り込みません（機器名が空の行は常に取り込みません）。こうした行はプレビューで「除外」になります。
- **既存の機器との照合**: 既存のグループへ取り込むとき、同じ機器を ①前回取り込んだときの元の名前（または「照合に使う列」＝資産番号などの値）→ ②機器名（大文字・小文字・全角・半角・空白、必要ならドメイン部・「-」と「_」の違いを無視）→ ③IP アドレス の順に探します。IP アドレスだけで一致した機器と、候補が 2 台以上ある行は、自動では結びつけず「要確認」にします。

ルールは各行の **「書き出し」**（`export\import-rules\ルール名.json`）と、見出しの **「ルールを読み込む」** で人に渡せます。書き出しには、パスワード系の欄の既定値・組み立て・置き換えの値と、パスワードを読む列への値の条件、見本ファイル名は含めません（受け取った人が入れます）。

### 取り込む

**「ファイルを選んで取り込む…」** でファイルを選ぶと、すぐに**プレビュー**の画面になります。この時点では何も変わりません。
変換ルールは、同じ名前のファイルで前回使ったルール（無ければ最後に使ったルール）が最初から選ばれ、取り込み先は、ファイル名と同じ名前のグループがあればその**既存のグループ**、無ければファイル名の**新しいグループを作る**が選ばれています。どちらも画面の上で変えられ、変えるとプレビューが作り直されます。
見出しの右に「ファイルを選び直す」「キャンセル」「取り込む」があり、プレビューの表の下（いつも画面の下端に見えています）にも件数と「キャンセル」「取り込む」があります。表は見出しを固定したまま、枠の中でスクロールします。

- 表の列: 「行」「判定」「機器名」「IPアドレス」「拠点名」「内容・変更点」「どの機器に」。
- 行ごとの判定: **追加** / **更新** / **要確認** / **取り込めない**（理由を表示）/ **変更なし** / **取り込まない**（「どの機器に」で取り込まないにした行）/ **除外**（変換ルールの除外条件に当てはまる行と、機器名が空の行）。判定の札（件数付き）を押すと、その種類の行の表示を切り替えられます。**除外の行は最初は隠れています**（「除外」の札を押すと表示されます）。
- 値の後ろの **「既定」** は空のときの既定値で埋めた値、**「推測」** は機種から推測した値です。既存の機器の更新では、項目ごとに「PalaTerm の値 / ファイルの値」と、どちらで変わったか（元のシステムで変更・PalaTerm で変更済み・両方で変更）が出ます。既存の機器の IP アドレスが変わる行もここに出るので、別の機器と取り違えていないか確かめてください。
- 「どの機器に」で結びつける機器を変えられます（新しい機器として追加 / 取り込まない / 候補の機器 / 「別の機器を選ぶ…」で名前・IP から選ぶ）。
- **このファイルに無い機器**は一覧で知らせるだけで、**削除しません**（チェックを入れたものだけ削除します。削除と要確認があるときは、取り込む前に両方確認します）。
- プレビューのあとでファイルが出力し直された・ルールを変えたときは取り込みを止め、新しいプレビューを出します。このとき行ごとの「どの機器に」の選択と削除の指定は取り消されるので、選び直してください。
- 結合セルが多すぎるシートは、多すぎる分の結合範囲を左上のセルだけに値があるものとして読み、プレビューに警告が出ます。
### 取り込み直したとき（手で直した値は戻しません）

機器ごと・項目ごとに**前回取り込んだ値**を保管庫（暗号化）に覚えておき、「前回の値・今回のファイルの値・PalaTerm の今の値」を比べます。

| 変わったところ | 結果 |
|---|---|
| 元のシステム側だけ | ファイルの値で更新 |
| PalaTerm 側だけ（手で直した） | PalaTerm の値を残す |
| 両方 | 要確認（初期選択は PalaTerm の値。行ごとに「ファイルの値にする」も選べます） |
| 前回の記録が無い（手で作った機器と名前が一致） | 違う項目だけ要確認 |

ファイルに無い列（列名が変わった・列が消えた）から読む項目は、**既存の機器では今の値をそのまま残し、空にはしません**。新しく追加する機器では既定値になり、既定値が無ければ空です。
列名が変わっただけなら、変換ルールでその列を選び直してください（プレビューの「ファイルに無い列」の注記にも同じ案内が出ます）。

取り込みで機器名が変わったときは、そのグループの予約の機器名も合わせて変わります。

## グループ未設定の機器

グループを削除したり、グループ欄を空にした機器は「グループ未設定」になります。グループ選択画面の **「（グループ未設定）n 台」** カードから開いて
編集・削除や、一括変更でのグループへの移動ができます（実行タブでも「（グループ未設定）」を選べます）。

## 機器一覧の一括変更・一括削除

機器一覧の左端のチェックで機器を選び（Shift+クリックで範囲・見出しで表示中の全行）、上に出るバーの **「一括変更…」** で
グループ（移動）・コマンドセット・OS タイプ・認証情報の扱い・拠点・役割を、選んだ機器にまとめて設定できます
（「（変更しない）」の項目はそのまま。移動先のグループに同じ機器名があるときは移動しません）。**「一括削除」** で選んだ機器を削除します。
**認証情報をまとめて変更**（v1.7.7・同じダイアログの折りたたみ）: 機器のユーザー名・パスワード・enable パスワードと、踏み台 n 段目のユーザー名・パスワードを、
チェックした項目だけ選んだ全機器に入れます（パスワードの定期変更に。踏み台はその段がある機器にだけ入ります）。
機器・コマンドセット・OS タイプの編集画面は **Esc** でも閉じられ、編集した内容があるときは「破棄して閉じますか？」と確認します。
**Ctrl+Enter** でどの編集画面も保存でき、コマンドセットの編集ではコマンド欄で **Enter** を押すと下に行が増えます（v1.7.7）。
機器の「複製」は、複製元の内容が入った未保存の機器として編集画面（「機器を複製」）が開きます（名前と IP を打ち直して保存。キャンセルすれば何も作られません）。
コマンドセット・OS タイプ・予約・変換ルールの「複製」も同じで、複製元の内容が入った未保存の編集画面が開き（名前は `元の名前_copy`。予約の名前は内容から自動）、「保存」するまで何も作られません。
一括変更の踏み台の段を選ぶ欄には、選んだ機器のうち何台にその段があるかが出て、結果の通知にも何台に踏み台の認証情報を入れたかが出ます。
その段の踏み台ホストが機器によって違うときは「⚠ この段の踏み台は n 種類あります」と出て、どの踏み台にも同じ値を入れるか、1 つの踏み台ホストの機器にだけ入れるかを選べます。
表の上での直接編集（IP・拠点・役割）は、保存のたびに表が描き直されてもカーソルが次のセルに残るので、Tab で流して直せます。

## 機器グループ（会社単位）と対象選択フロー

機器は**グループ（会社・拠点など）単位**で管理します。「機器一覧」タブを開くと、まず
**グループ選択画面**が出ます。ここで次のいずれかを選びます。

- **＋ 新規グループ作成**: グループ名（例: A社）を入力して作成 → そのグループの空の一覧に移り、機器を追加していきます（追加した機器は自動でそのグループ所属）
- **既存グループ**: そのグループの機器一覧に移ります
- **全機器**（グループが 2 つ以上あるとき）: すべてのグループの機器を 1 つの一覧で表示します（「グループ」列と「グループ: すべて」の絞り込みがあり、どのグループにある機器か探すときに）

グループ選択画面ではカードを**ドラッグして並び順を変更**（保存されると「並び順を保存しました」と表示）、
各カードの**「複製」**でグループを丸ごと複製できます（既定の認証情報と機器を新しいグループ名でコピー。機器名はそのまま。接尾辞を入力すれば末尾に付きます）。機器名は同じグループの中でだけ重複できません（別のグループなら同じ名前を使えます）。グループ内一覧では上部の
「グループ名変更」「グループ削除」が使えます（削除しても機器は残り、グループ未設定になります）。
機器の所属は、機器編集の「グループ」欄の「別のグループへ移す…」（未設定なら「グループを選ぶ…」）でも変更できます。機器には**拠点（任意）**と**役割（任意）**も設定でき（一覧のセルでも直接編集可）、
パスワード欄は**目のマーク**で表示/非表示を切り替えられます。実行タブのグループ選択で、その
グループの機器だけを実行対象にできます。

**一式書き出し・読み込みはグループ単位**です。書き出しは対象グループ（または全機器）を選択、
読み込みはファイルのグループをそのまま使うか、まとめて特定グループへ割り当てるかを選べます。
CSVには group / site / role 列が含まれます（パスワードは平文なので取扱注意）。
コマンドセット・OSタイプ設定の各タブには単体ファイルの「読み込み」だけが残っています
（旧ツールの `.list` 形式の取り込みや、削除した標準プロファイルの復元用）。同じ名前のコマンドセット・OS タイプが既にあって中身が違うときは、
「置き換える」「別名で追加（名前）」「やめる」から選びます（同じ中身なら「「X」は同じ内容で登録済みです」と出るだけです）。

## ログの保存先・命名

- 保存先: 「設定」タブの「ログ保存フォルダ」（既定 `logs`）配下に、
  実行ごとのフォルダ（既定 `{date}_{time}_{group}_{stage}` ＝ `YYYYMMDD_HHMMSS[_グループ][_作業タイミング]/`）が作られます。フォルダ名は
  「ログフォルダ名テンプレート」で変更可（`{date} {time} {hhmm} {group} {stage}`。例 `{date}_{group}_{stage}`。
  同名フォルダが既にあれば `_2`, `_3` … が付きます）。旧既定 `log_{date}_{time}_{stage}` のままの vault はロック解除時に新既定へ移行します（自分で変えたテンプレートはそのまま）。
  実行履歴はフォルダ内の `palaterm-run.json` で実行を判別するので、フォルダ名を変えても一覧に出ます。
  「ログ保存フォルダ」は保存するときに前後の空白と引用符（エクスプローラーの「パスのコピー」で付く `"`）を外し、作れない・書き込めないフォルダは
  「ログの保存先フォルダ「…」に書き込めません: …」のように理由を出して保存しません。実行のときに書き込めなくなっていれば、機器に接続する前に止まります（一括実行・予約とも）。
- ファイル名テンプレート（既定 `{host}_{site}_{role}_{stage}_{date}_{time}.txt`）で
  次のプレースホルダが使えます: `{host} {ip} {os} {group} {site} {role} {stage} {date} {time} {hhmm}`
  （`{stage}` は作業タイミング: 指定なし=`Current`（v1.7.1 までは `Config`）・作業前=`before`・作業中=`work`・作業後=`after`・予約=`reserve`。
  これらの語は「設定」の「ログ名に付く作業タイミングの語」で変更できます（空欄=既定。指定なしの語はファイル名にだけ付きます）。
  改名しても、以前の既定語で作られたフォルダは実行履歴でそのまま判別されます。
  拠点・役割が空なら `{site}` / `{role}` の分は詰められます。以前の既定（`{host}_Config_{date}_{time}.txt`・`{host}_{site}_{stage}_{date}_{time}.txt`）のままの設定は自動で新既定に移行します）
- 対話接続のログも同じテンプレートで、作業タイミング `work` として `日時_グループ_work/` フォルダに保存され、
  「実行履歴」に「対話接続」として並びます。

## 設定（「設定」タブ）

- **最大並列数**: 同時接続数（0 = 無制限）
- **接続タイムアウト / コマンドタイムアウト**（秒）
- **アイドル時の自動ロック**（分・既定 30・0 = 無効）: マウス・キーボード操作がこの時間なければ
  自動でロック画面に戻ります。**一括実行中もロックします**（v1.7.7。実行は裏で続き、解除すると進捗表に戻ります）。
  編集中のダイアログがあった場合は破棄され、解除後にその旨が表示されます。対話接続ウィンドウは、それぞれ自分の操作がこの時間なければロックします。
  GUI の窓での操作も本体の操作として数えるので、使っている最中の GUI の窓がロックで閉じられることはありません。
- **ログ名に付く作業タイミングの語**（v1.7.6 まで「作業タイミングの付与文字列」）: `{stage}` に入る `before` / `work` / `after` などの語を変えます（下の「ログの保存先・命名」参照）。
- **ログ内のパスワードをマスクする**（既定オフ）。コマンドセットの行に `{password}` / `{enable}` を書いた場合だけは、
  この設定に関係なくその実行のログをマスクします（機器がコマンド行をエコーするため）。
- **危険な操作**（設定タブの最下部・v1.7.7 でサイドバーから移動）: 「すべてのデータをリセット（初期化）」。
  2 回の確認とマスターパスワードの入力で、すべての機器・グループ・コマンドセット・OS タイププロファイル・マスターパスワードを削除します（ログと export は残ります）。
- **自分の踏み台**（v1.7.4）: 社内の踏み台など、人ごとに秘密鍵が違う踏み台を**最大5段**まで登録します（段ごとにホスト・接続方式・ポート・ユーザー・認証方式・パスワードまたは秘密鍵と鍵のパスフレーズ・旧暗号・ジャンプコマンド。専用の「保存」ボタン）。
  機器で「自分の踏み台（設定タブ）を先に通る」にチェックすると、ここの踏み台を順に通ります。この PC の vault にだけ暗号化して保存され、一式書き出し・CSV には入りません。
  v1.7.3 の「自分の踏み台認証」は、ロック解除時に自動でここへ移ります（1 件目を自分の踏み台にし、1 段目がそのホストで認証欄が空だった機器はチェック付きに変わります）。
- **対話窓の右クリック**: Tera Term の［その他の設定］-［コピーと貼り付け］と同じ 2 項目。
  「マウス右ボタンでの貼り付けを無効にする」（右クリックで何もしない）・「〃確認する」（右クリックで出るメニューの「貼り付け」で貼り付け）。
  どちらもオフ（既定）なら右クリックですぐ貼り付け、「無効にする」がオンならもう一方は無視。変更はこのあと開く対話窓から反映されます。
- **並べて接続の同時入力**（v1.8.0・既定オフ）: オンにすると、「並べて接続」で開いた窓が最初から同時入力オンになります。オフなら各窓の「同時入力」で必要な窓だけオンにします（1 台ずつ開いた窓は常にオフで開始）。
- **表示の色**（v1.8.0）: 対話窓・ログ表示・画面表示・差分の文字色・背景色（上の「表示の色・端末の色」参照）。

### コマンドに書ける変数と注意

コマンドセットのコマンドには `{user}` `{password}` `{enable}` が使え、機器の認証情報に置き換わって送られます
（例: `copy running-config scp://{user}@192.0.2.10/backup.cfg`）。機器はコマンド行をエコーするため、`{password}` / `{enable}` を書いた行を含むセットの
実行ログは、マスク設定に関係なく `****` に置き換えて保存します（v1.7.7）。こうした行は、実行前の確認と一式読み込みの確認画面に
「パスワードを送るコマンド」として列挙されるので、送り先（例: `ping {password}.example` のような外部へ送る行）を確認してください。
