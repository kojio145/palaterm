# 使い方

## 初回起動

1. Releases の `PalaTerm-vX.Y-win64.zip` を展開し、`PalaTerm` フォルダごと好きな場所に置いて、中の `PalaTerm.exe` をダブルクリック（インストール不要。データ・ログ・書き出しはこのフォルダの中に作られます）。
2. 初回はマスターパスワードを設定します。機器の認証情報はこのパスワードで
   AES-256-GCM 暗号化され、`PalaTerm.exe` の隣の `data\palaterm_vault.enc` に
   保存されます。**平文では一切保存されません。**
3. 2 回目以降はマスターパスワードでロック解除します。

> 持ち運び: `PalaTerm.exe` と `data\` フォルダを一緒に USB 等へコピーすれば
> どの Windows でもそのまま使えます。
>
> 書き込み先: PalaTerm のデータ（vault・ログ・書き出し）はすべて exe の隣に作られます。
> 唯一の例外は WebView2 ランタイム自身のブラウザキャッシュで、Windows が
> `%APPDATA%\PalaTerm.exe\EBWebView\` に作ります（PalaTerm のデータは含まれません）。
> アンインストールは exe のフォルダの削除だけで済みます（必要ならこのキャッシュも削除してください）。

## 基本の流れ

### 1. コマンドセットを作る（「コマンドセット」タブ）

実行したいコマンドを 1 行 1 コマンドで登録します。例（設定バックアップ）:

```
show running-config
show version
show ip interface brief
```

### 2. 機器を登録する（「機器一覧」タブ）

「＋ 機器を追加」から以下を設定します。

- **名前**: ログファイル名に使われます（例: `core-sw1`）
- **ホスト / IP**、**接続方式**（SSH / Telnet / シリアル）
- **OSタイプ**: ログイン自動化のプロファイル（Cisco IOS / ASA, JUNOS, FortiGate,
  HPE, NEC IX/QX/WA, A10, Aruba, ALAXALA AX, Yamaha RTX など 15 種）
- **拠点（任意）／役割（任意）**: 本社・東京DC、コア・エッジ・FW などの自由なラベル。
  ログファイル名テンプレートの `{site}` / `{role}` に入ります
- **コマンドセット**: 上で作ったセットを割り当て
- **認証情報**: ユーザー名 / パスワード / enable パスワード
  （SSH は公開鍵認証も選択可。Ed25519 / RSA / ECDSA 対応・パスフレーズ付き鍵可）
- **踏み台サーバ**（任意）: 「＋ 踏み台を追加」で**最大5段**まで登録可。外側（手前）から順に、
  各段の接続方式（SSH/Telnet）・ホスト・認証を設定します。公開鍵認証とレガシー暗号の許可は **1段目のみ**。
  2段目以降と対象機器へは手前の踏み台上で `ssh` / `telnet` を打って進むため、認証はその踏み台側の
  ssh クライアント（`~/.ssh` の鍵など）に依存します（ここで使われるのはユーザー名とパスワードだけ）。

**一式書出・読込（CSVでの一括登録もここ）**: 機器一覧の「一式書出」で、対象グループ（または全機器）の
機器CSV（`devices.csv`）と、その機器が使う**コマンドセット・OSタイププロファイル**を
`export\bundles\グループ名\` にまとめて書き出します（「全機器」はコマンドセット・プロファイルも全件含む完全なバックアップ）。
別の PalaTerm では「読込」でそのフォルダの `palaterm-bundle.json` を選ぶと一式が入ります。
`devices.csv` は Excel 等で編集でき、「読込」で CSV 単体を選べば機器だけを読み込めます（機器名をキーに、既存は更新・新規は追加）。
読み込む前に、新規・上書き・既存のまま残す件数が確認画面に出ます。同名のコマンドセット・プロファイルは
既定では既存を残し（他グループの設定を壊さないため）、チェックを入れた場合だけ上書きします。
CSV の踏み台チェーンは1列に `method:host:port:user:pass:auth:keyfile` を `|` で区切って複数段書け、
ジャンプコマンド・鍵パスフレーズ・レガシー暗号の有無は隣の `bastionExtras` 列（JSON）に入るので、CSV だけで機器を完全に復元できます。
※CSVには**パスワードが平文で書き出されます**。編集後は速やかに削除してください。

**一覧上で直接編集・複製・削除**: 機器一覧の表では、ホスト・接続方式・OS・コマンドセットを
セルで直接編集できます（編集内容は自動保存。認証情報や踏み台は「詳細」ボタンから）。各行の
「複製」で機器をコピー、「削除」で削除できます。ヘッダーのチェックボックスで**全選択/全解除**できます。

**入力チェック**: 保存時に、IPアドレス形式（例: `192.168.1111.1` のような不正値は拒否）・
必須項目・ポート範囲などを検証し、問題があればエラーを表示して保存しません。

**機器グループ**: 「機器グループ」ボタンから、よく使う機器の組み合わせを名前付きで保存できます。
機器一覧のグループ・チップや、実行タブのグループ選択から、そのグループの機器だけをワンクリックで
実行対象にできます。

**グループ既定の認証情報**: グループ内の機器が同じユーザー名・パスワードでログインする場合は、
グループの機器一覧上部の「グループ既定の認証情報…」で一度だけ登録し、機器側は編集画面の
「認証情報の扱い」を**「グループ既定を使う」**にします（一覧に「既定」バッジが付きます）。
同じグループでもパスワードが違う機器は**「この機器に個別に設定」**のままにすれば、その機器だけ自分の
認証情報でログインします。ダイアログの「全機器を切り替える」で一括切替もできます。

### 3. 一括実行（「実行」タブ）

- 機器一覧でチェックを入れた機器が対象です。列見出しで並び替え、表の上の絞り込み（文字・拠点・状態）で
  表示を絞れます。**絞り込み中は表示中の機器だけが実行対象**（非表示でチェック済みの台数を警告表示）。
- **作業タイミング**（指定なし / 作業前 / 作業中 / 作業後）を選んで実行すると、ログのフォルダ名と
  ファイル名に `_before` / `_work` / `_after` が付き、「実行履歴」タブで作業前と作業後を比較できます
  （付与する文字列は「ログ設定」で変更できます）。
- **⚡ 接続確認のみ**: 接続とログインだけを行い、コマンドは送らずログも残しません（認証情報・到達性の事前確認）。
- **設定変更コマンドの事前警告**: コマンドセットに `conf t` / `write` / `reload` / `no …` /
  `erase` など機器を変更するコマンドが含まれていると、実行前にそのコマンドを列挙した警告が出て、
  「変更を伴うことを理解したうえで実行します」にチェックしないと実行できません。
- 「▶ 一括実行」で全対象へ並列接続。各機器の状態（接続中 / ログイン中 /
  実行中 / 完了 / エラー）がリアルタイムに表示されます。実行中は機器ごとに
  完了数/全体数と「残り 約n秒」（その機器の残りコマンド全部が終わるまでの概算）が出ます。
- 完了後、各行の「ログ表示」でログを別ウィンドウに開けます（検索・文字サイズ変更・全文コピー・再読込）。
  対話接続のツールバーにも「ログ表示」があり、書き込み中のログを自動で追います。
- 「ログフォルダを開く」で保存先を開きます。
- **中止**: 「■ 中止」を押すと（確認のうえ）実行中の機器は打ち切り、未実行の機器は開始しません。
  打ち切られた機器と未実行の機器は「中止」と表示され、完了済みの機器のログはそのまま残ります。
  その後は「▶ 一括実行」（最初から全部）・「↻ 失敗・中断のみ再実行」（完了済みはそのまま）・
  「✕ 結果をクリア」（表を待機に戻す）から選べます。

### 4. 実行履歴と作業前後の比較（「実行履歴」タブ）

一括実行のたびにログフォルダ内の `log_日時[_作業タイミング]/` に `palaterm-run.json`（機器ごとの成否・
ログファイル名）が残り、「実行履歴」タブに新しい順で並びます。▸ で機器ごとの結果と「ログ表示」、
「フォルダ」でエクスプローラーを開けます。

**比較**: 2 回の実行を A（作業前）/ B（作業後）に選んで「比較する」と、同じ機器名のログ同士を突き合わせ、
機器ごとに「差分なし／差分あり（追加・削除行数）」が出ます。「差分を開く」で WinMerge 風の別ウィンドウ
（左 A・右 B、変更行は黄・A のみ赤・B のみ緑、位置バー、前後の差分へ移動、Esc で閉じる）が開き、
「時刻・カウンタの違いを無視」（既定オン: `show clock` の時刻や uptime、トラフィック量の違いを
差分扱いにしない）と「差分の周辺だけ表示」を切り替えられます。
「作業中（任意）」に A と B の間の作業（作業中の一括実行または単独接続）を選ぶと、作業中のログから
投入した設定コマンド行を抜き出し（show 系・exit/end・write 等は除外）、作業後のログに 1 件ずつあるか照合します
（`no …` は対象行が消えていれば反映）。機器ごとに「✅ n 件すべて反映／⚠ m / n 件が未反映」と各行の ✓ ✗、
全体に「作業中に設定した内容（c 件）が、作業後に全 n 台で反映されています」等の結論が出ます。
作業後の取得には show running-config 相当を含めてください。

## 対話接続（1台に手動ログイン）

機器一覧または**実行タブ**の各行の **「接続」** ボタンで、その1台にログイン・enable昇格・
ページャ無効化まで自動で済ませた状態の端末が、**本ツールとは独立した別ウィンドウ**（タスクバーにも
別表示）で開きます。**複数機器へ同時に別ウィンドウで接続**でき、各ウィンドウは四辺・四隅から
自由にリサイズできます（表示列数も追従）。踏み台経由でも自動で通り抜けます。対話接続の内容も
**ログファイルに保存**されます（切断時に保存先を表示）。`exit` またはウィンドウを閉じて終了します。

貼り付けは **Ctrl+V**（Shift+Insert / Ctrl+Shift+V も可）、または **Alt+V**（Tera Term の「貼り付け<CR>」相当）、
**右クリック**、ツールバーの「貼り付け…」。いずれも Tera Term と同様に**貼り付ける内容の確認が別ウィンドウ**で開き（端末の手前・移動やサイズ変更可）、
内容を見て（必要なら編集して）「貼り付け」または Enter で送ります（Alt+V は「最後に Enter を送る」がオン）。
Windows のクリップボード履歴（Win+V）から選んだ項目も同じ確認を経ます。複数行は各行末が Enter として送られます。
コピーは Tera Term と同じく**マウスで範囲を選択するだけ**で自動的にクリップボードへ入り、バーに「コピーしました」と出ます
（ダブルクリックで単語選択）。Ctrl+C はコピーではなく機器への中断（^C）送信です。
ツールバーの「ログフォルダ」でログの保存先フォルダを開けます。対話接続のログは Tera Term と同様に**画面に出た内容がそのままリアルタイムでファイルへ書かれます**
（既定ではそのまま記録。「ログ設定」の「ログ内のパスワードをマスクする」をオンにすると、機器のパスワードが現れた箇所を `****` に置き換えて保存します）。ツールバーの「ログ停止」で記録を止め、「ログ開始」で同じファイルに続きを記録します（停止・再開の時刻がファイルに記されます）。
**文字サイズ**は「A−」「A＋」・Ctrl+ホイール・Ctrl+「+」「−」で変更（Ctrl+0 で既定に戻す・次回も保持）、
**検索**は Ctrl+F または「検索」ボタン（Enter で次・Shift+Enter で前・Esc で閉じる）。

## 機器グループ（会社単位）と対象選択フロー

機器は**グループ（会社・拠点など）単位**で管理します。「機器一覧」タブを開くと、まず
**グループ選択画面**が出ます。ここで次のいずれかを選びます。

- **＋ 新規グループ作成**: グループ名（例: A社）を入力して作成 → そのグループの空の一覧に移り、機器を追加していきます（追加した機器は自動でそのグループ所属）
- **既存グループ**: そのグループの機器一覧に移ります
- **全機器**: すべての機器を表示します

グループ選択画面ではカードを**ドラッグして並び順を変更**（保存されると「並び順を保存しました」と表示）、
各カードの**「複製」**でグループを丸ごと複製できます（既定の認証情報と機器を新しいグループ名でコピー。機器名には接尾辞が付きます）。グループ内一覧では上部の
「グループ名変更」「グループ削除」が使えます（削除しても機器は残り、グループ未設定になります）。
機器の所属は、機器編集の「グループ（会社）」欄でも変更できます。機器には**拠点（任意）**と**役割（任意）**も設定でき（一覧のセルでも直接編集可）、
パスワード欄は**目のマーク**で表示/非表示を切り替えられます。実行タブのグループ選択で、その
グループの機器だけを実行対象にできます。

**一式書出・読込はグループ単位**です。書き出しは対象グループ（または全機器）を選択、
読み込みはファイルのグループをそのまま使うか、まとめて特定グループへ割り当てるかを選べます。
CSVには group / site / role 列が含まれます（パスワードは平文なので取扱注意）。
コマンドセット・OSタイプ設定の各タブには単体ファイルの「読込」だけが残っています
（旧ツールの `.list` 形式の取り込みや、削除した標準プロファイルの復元用）。

## ログの保存先・命名

- 保存先: 「設定」タブの「ログ保存フォルダ」（既定 `logs`）配下に、
  実行ごとのフォルダ（既定 `log_YYYYMMDD_HHMMSS[_作業タイミング]/`）が作られます。フォルダ名は
  「ログフォルダ名テンプレート」で変更可（`{date} {time} {hhmm} {group} {stage}`。例 `{date}_{group}_{stage}`。
  同名フォルダが既にあれば `_2`, `_3` … が付きます）。
- ファイル名テンプレート（既定 `{host}_{site}_{stage}_{date}_{time}.txt`）で
  次のプレースホルダが使えます: `{host} {ip} {os} {group} {site} {role} {stage} {date} {time} {hhmm}`
  （`{stage}` は作業タイミング: 指定なし=`Config`・作業前=`before`・作業中=`work`・作業後=`after`。
  作業前／作業中／作業後の 3 語は「ログ設定」の「作業タイミングの付与文字列」で変更できます（空欄=既定）。
  改名しても、以前の既定語で作られたフォルダは実行履歴でそのまま判別されます。
  拠点・役割が空なら `{site}` / `{role}` の分は詰められます。旧既定 `{host}_Config_{date}_{time}.txt` のままの設定は自動で新既定に移行します）
- 対話接続のログも同じテンプレートで、作業タイミング `work` として `log_日時_work/` フォルダに保存され、
  「実行履歴」に「単独接続」として並びます。

## 設定（「設定」タブ）

- **最大並列数**: 同時接続数（0 = 無制限）
- **接続タイムアウト / コマンドタイムアウト**（秒）
- **アイドル時の自動ロック**（分・既定 30・0 = 無効）: マウス・キーボード操作がこの時間なければ
  自動でロック画面に戻ります（一括実行中はロックしません。対話接続ウィンドウは別プロセスなので影響しません）。

## 注意

- 本ツールは機器の設定変更（コマンド投入）も行えます。**本番機器での利用は
  必ず検証環境で確認し、所属組織のルールに従ってください。**
- 会社 PC で利用する場合は、自作ツールであっても社内の利用申請ルールを
  確認してください。
