Code signing policy

PalaTerm — batch SSH / Telnet / serial login tool for network engineers (Windows, MIT License)

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Releases of PalaTerm are distributed only from the project's GitHub Releases page. A signed release contains only programs built from the source code in this repository; third-party Go modules are compiled into the executable from their published source, and no binary from another vendor is signed.

Team roles

Committers and reviewersKJO (repository owner)
ApproversKJO (repository owner)
  • PalaTerm has a single maintainer. Changes proposed by anyone else (pull requests) are reviewed by the maintainer before they are merged.
  • Every signing request is approved manually by an approver; nothing is signed automatically.
  • All team members use multi-factor authentication for GitHub and SignPath.

How releases are built

  • Each release tag is built by GitHub Actions with the workflow .github/workflows/build.yml: go vet, go test, then go build -trimpath -buildvcs=false -tags production.
  • The build is reproducible: the same source and Go version produce the same bytes. The SHA-256 of PalaTerm.exe is published in each release note and in the workflow run's summary, and anyone can rebuild it with the steps in BUILD.md to compare.
  • The executable's product name is PalaTerm and its version matches the release tag.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

  • PalaTerm connects only to the network devices and jump hosts the user configures, over SSH, Telnet or a serial port, when the user runs a task or opens a session. It has no telemetry, no crash reporting, no update check and no advertising.
  • Device entries, credentials (in an AES-256-GCM encrypted vault) and session logs are stored only in the folder next to the executable. Details: security review record.
  • The user interface is rendered by the Microsoft Edge WebView2 Runtime that is part of Windows. That component is governed by the Microsoft Privacy Statement.

Installation and removal

PalaTerm needs no installer and does not change the system configuration or the registry. To remove it, delete its folder (and, optionally, the two small settings folders listed in the README).
