PalaTerm

複数のネットワーク機器へ SSH / Telnet / シリアルで一括ログインし、コマンドを並列実行する Windows 用ツール

数十台のルータ・スイッチ・ファイアウォールに同時ログインしてログを採取し、コマンドセットを一括実行し、設定変更を並列で流し込む。 PalaTerm は Tera Term マクロや手作業のログ取得を置き換えるために作った、ネットワークエンジニア向けの一括ログインツールです。 単一のポータブル exe で動き、インストールは不要です。

PalaTerm.exe をダウンロード（GitHub Releases） 使い方マニュアル ソースコード（GitHub）

現在 v1.3（β）。Windows 10 / 11（x64）。未署名のため初回起動時に SmartScreen の警告が出ることがあります（「詳細情報」から「実行」）。MIT ライセンス・商用利用可。

できること

同時ログイン機器リストの全台へ並列接続。同時実行数は調整できます。
3 つの接続方式SSH / Telnet / シリアルコンソール（COM ポート自動探索）。
踏み台（多段）対応踏み台サーバ経由の多段接続。SSH 公開鍵認証（Ed25519 / RSA / ECDSA、パスフレーズ付き鍵）に対応。
ログイン自動化Cisco IOS / ASA、JUNOS、FortiGate、HPE、NEC IX、Yamaha RTX など 14 種の OS プロファイル内蔵。enable 昇格やページャ無効化まで自動。プロファイルは編集・自作可。
コマンド一括実行名前付きコマンドセットを機器ごとに割り当てて一括実行。
ログ自動保存{host}_Config_{date}_{time}.txt 形式で保存。命名はプレースホルダで変更可。
認証情報の暗号化保存マスターパスワードによる AES-256-GCM 暗号化。平文では保存しません。
対話接続1 台へのログイン自動化を済ませてから内蔵ターミナル（xterm.js）で手動操作に引き継げます。
外部通信ゼロテレメトリなし・自動更新なし。閉域の社内ネットワークでの利用を想定した設計です。

こんな場面に

  • 作業前後で数十台の show running-config / show tech-support を一度に取得して差分を取りたい
  • 同じ設定変更を複数台に並列で投入し、結果ログを機器ごとに残したい
  • Tera Term マクロの保守が限界で、機種ごとのログイン手順（enable・ページャ）を GUI で管理したい
  • 踏み台を 2 段挟んだ先の機器にも同じ手順で入りたい

使い方

  1. Releases から PalaTerm.exe をダウンロードして起動（インストール不要）
  2. 初回にマスターパスワードを設定し、機器リストとコマンドセットを登録
  3. 実行タブで対象機器とコマンドセットを選んで一括実行。ログは exe と同じフォルダの logs/ に保存されます

詳しくは 使い方マニュアル、USAGE.md、セキュリティレビュー記録 を参照してください。

English

PalaTerm is a batch login tool for network engineers: parallel SSH / Telnet / serial access to many network devices, batch command execution and automatic log saving, shipped as a single portable Windows executable. A Tera Term macro alternative. See the GitHub repository for the English README.
