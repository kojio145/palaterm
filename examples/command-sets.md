# コマンドセットの例

「コマンドセット」タブに貼り付けて使えるコマンド例です（1 行 1 コマンド）。

## Cisco IOS: 設定バックアップ

```
show running-config
show version
show ip interface brief
show cdp neighbors detail
```

## Cisco IOS: 障害調査

```
show logging
show processes cpu sorted
show interfaces | include line protocol|error
show ip route summary
```

## FortiGate: 設定確認

```
show full-configuration
get system status
get router info routing-table all
diagnose sys session stat
```

## Juniper JUNOS: 状態確認

```
show configuration | display set
show chassis hardware
show interfaces terse
show route summary
```

## Yamaha RTX: 設定・状態

```
show config
show environment
show status lan1
show ip route
```
